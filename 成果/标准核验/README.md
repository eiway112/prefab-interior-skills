# 标准核验（输出物目录）

本目录收录 scanned-standard-clause-verify 技能（IC-11 接收方）执行标准条文核验后产出的正式核验报告。

## 命名规则

`标准编号_核验报告_YYYYMMDD.md`

示例：`T-CECS 1018-2022_核验报告_20260813.md`（文件名中 `/` 以 `-` 替代）。

## 报告内容要求

每份核验报告须包含：

1. 身份核验：公告号、发布机构、发布日期、实施日期、主编单位、出版信息（逐项标注核验来源：封面/公告页/官方平台），版本形态（扫描版/文本版）
2. 条文核对表：条文号 | 核验内容 | 原文摘录 | 页码/位置 | 结论（一致/不一致/不存在）
3. 核验结论：S1 确认属实 / 待官方核验 / 无法核验（S1 须"官方发布 + 官方文本核验"两要素齐备，见 SSCV-R-P0-1）
4. 未决事项：核验不通过或无法核验的引用点清单及处理建议

## 边界

- 仅收录正式核验报告；过程性中间产物（渲染影像、抓取原文、OCR 草稿）不进入本目录
- 核验结论的索引登记在 `_专题_技能合集策划/standards-index.md`，治理登记在 `change-governance.md`
