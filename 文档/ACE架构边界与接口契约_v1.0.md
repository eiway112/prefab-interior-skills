## 一、ACE 通用化定位与能力声明

### 1.1 定位升级

ACE（acoustic-calculation-engine）从隔墙技能的专属隔声计算模块，升级为覆盖装配式装修全品类的**通用隔声计算引擎**。其核心设计理念是：

> **底层物理模型通用化，上层评价量和构造规则由各技能注入。**

| 维度 | 隔墙场景（原 IC-03） | 楼地面场景（新增 IC-08） | 吊顶场景（新增 IC-09） |
|------|-------------------|----------------------|---------------------|
| **评价量** | Rw+C / Rw+Ctr / DnT,w+C（空气声隔声） | Ln,w / ΔL（撞击声隔声） | Rw+C / Rw+Ctr（空气声隔声，侧向传声修正） |
| **声源类型** | 空气声（声源室 → 接收室） | 撞击声（标准锤击器 → 楼板 → 接收室） | 空气声（侧向/直接传声混合） |
| **核心物理模型** | 质量定律、MSM、吻合效应、声桥修正 | 质量定律、面层动态刚度、垫层隔振、接收室修正 | 质量定律、MSM（吊顶面板+空腔）、吻合效应、缝隙修正 |
| **构造要素** | 板材、龙骨、空腔、填充、密封 | 楼板基层、垫层/面层、弹性垫、浮筑构造 | 吊杆、吊顶面板、空腔、填充、收口密封 |
| **精度声明** | ±3-5 dB | ±4-6 dB（撞击声离散性更大） | ±4-6 dB（侧向传声不确定性） |

### 1.2 能力声明

ACE 提供以下**通用计算能力**：

1. **质量定律估算**：基于面密度的基础隔声量估算（空气声）或撞击声改善量估算（撞击声）
2. **吻合效应分析**：临界频率计算与风险提示（适用所有板材构造）
3. **空腔/多层构造增益估算**：MSM 模型或等效空腔增益模型（适用龙骨隔墙、隔声吊顶、浮筑地面）
4. **声桥/刚性连接风险**：识别构造中的刚性连接对隔声性能的削弱
5. **密封/缝隙风险评估**：评估构造密封连续性对隔声性能的影响
6. **敏感性分析**：关键参数（面密度、空腔深度、填充材料）变化对结果的敏感性

ACE **不做以下事情**：

1. 不做"是否满足标准限值"的合规判断——该判断由调用方基于各自技能 A1 性能指标表完成
2. 不替代实验室检测报告或现场实测——输出始终标注"专业估算"
3. 不处理超出适用边界的构造——返回"超出模型适用范围"
4. 不覆盖现场侧向传声、门窗薄弱构件、施工质量离散等不可建模因素

## 二、底层物理模型架构（通用内核）

### 2.1 通用物理模型层

ACE 的底层计算内核由以下物理模型组成，**不绑定任何特定部品系统**：

```
┌─────────────────────────────────────────────────────────────┐
│                    ACE 通用物理模型层                         │
├─────────────────────────────────────────────────────────────┤
│  M1. 质量定律模型（Mass Law）                                 │
│      └─ 单层均质板 Rw ≈ 20·log10(m·f) - 47.2               │
│      └─ 输入：面密度 m(kg/㎡)、频率 f(Hz)                   │
│      └─ 适用：所有板材构造的空气声隔声基础估算               │
├─────────────────────────────────────────────────────────────┤
│  M2. 吻合效应模型（Cremer 薄板理论）                          │
│      └─ fc = c²/(2π·h) × √(12(1-σ²)·ρ/E)                   │
│      └─ 输入：板厚 h(m)、密度 ρ(kg/m³)、弹性模量 E(Pa)       │
│            泊松比 σ                                          │
│      └─ 适用：所有薄板构造的吻合谷风险识别                   │
├─────────────────────────────────────────────────────────────┤
│  M3. 质量-弹簧-质量模型（MSM）                                │
│      └─ f₀ ≈ 600/√(d·m_red)  （d 用 cm）                    │
│         m_red = m₁·m₂/(m₁+m₂)  约化面密度                   │
│      └─ 输入：空腔深度 d(cm)、两侧面板面密度 m₁,m₂(kg/㎡)   │
│      └─ 适用：双层板+空腔构造（龙骨隔墙、隔声吊顶）          │
├─────────────────────────────────────────────────────────────┤
│  M4. 空腔增益叠加模型                                         │
│      └─ 空腔增益：≥75mm 空腔 +3~8 dB（按总深度判定）        │
│      └─ 填充增益：岩棉/玻璃棉 +2~5 dB（按填充率判定）       │
│      └─ 解耦增益：弹性连接/解耦构造 +3~10 dB                │
│      └─ 适用：多空腔构造（一体化双空腔龙骨、隔声吊顶）       │
├─────────────────────────────────────────────────────────────┤
│  M5. 撞击声改善模型（撞击声场景专用）                         │
│      └─ ΔL ≈ 40·log10(f/f₀)  或基于动态刚度的经验模型        │
│      └─ 输入：面层/垫层面密度、弹性垫动态刚度 s(MN/m³)       │
│      └─ 适用：浮筑地面、楼面垫层撞击声改善估算               │
├─────────────────────────────────────────────────────────────┤
│  M6. 声桥/缝隙修正模型                                        │
│      └─ 声桥修正：刚性连接处隔声量下降 3~10 dB               │
│      └─ 缝隙修正：缝隙面积比 → 隔声量下降估算                │
│      └─ 适用：所有构造的节点风险识别                         │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 材料参数库（通用）

ACE 维护一份**通用材料参数表**，各技能调用时按实际构造选择对应材料：

| 材料类别 | 参数项 | 典型取值范围 | 来源标准 |
|---------|--------|------------|---------|
| 石膏板 | 密度 ρ、弹性模量 E、泊松比 σ、面密度 | ρ 700-900 kg/m³, E 2.0-2.5 GPa | GB/T 9775-2025 |
| 硅酸钙板 | 密度 ρ、弹性模量 E、泊松比 σ、面密度 | ρ 1000-1400 kg/m³, E 6-8 GPa | JC/T 564.1-2018 |
| 纤维水泥板 | 密度 ρ、弹性模量 E、泊松比 σ、面密度 | ρ 1300-1800 kg/m³, E 8-12 GPa | JC/T 412.1-2018 |
| ALC 条板 | 密度 ρ、弹性模量 E、泊松比 σ、面密度 | ρ 500-700 kg/m³, E 1.5-2.0 GPa | GB/T 23451-2023 |
| 岩棉 | 容重、流阻 | 容重 40-120 kg/m³ | GB/T 11835-2016 |
| 玻璃棉 | 容重、流阻 | 容重 24-48 kg/m³ | GB/T 13350-2017 |
| 浮筑垫层 | 动态刚度 s、厚度 | s 5-50 MN/m³ | 产品检测数据 |
| 吊顶面板 | 密度 ρ、弹性模量 E、面密度 | 同石膏板/硅酸钙板/金属板 | 对应产品标准 |

> **参数使用规则**：方法论层计算必须使用参数表中的标准参数范围，不得因某产品的特定参数而改变计算逻辑（对应红线 ACE-R-P1-3 / PW-R-P1-8）。

## 三、适用边界表（按调用方分类）

> **使用说明**：ACE 在建立公式库前，必须先声明适用范围、不可处理范围和输出确定性等级。凡超出适用边界的输入，不得继续给出确定数值，只能返回"超出模型适用范围/需人工评估"。

### 3.1 隔墙技能调用边界（空气声隔声）

| 构造类型 | 可支持能力 | 输出等级 | 不得覆盖的范围 |
|---------|-----------|---------|---------------|
| 单层板/单一均质墙体 | 基于面密度的质量定律估算、吻合效应风险提示 | 专业估算 | 不替代实验室 Rw 检测报告 |
| 双层板龙骨墙 | MSM 共振频率、空腔深度、填充材料、连接方式影响判断 | 专业估算 | 不处理复杂节点侧向传声 |
| 双排龙骨/解耦构造 | 双空腔、解耦连接、岩棉填充对中高频隔声的风险判断 | 专业估算，需列关键假设 | 不保证现场 DnT,w+C 达标 |
| ALC/轻质条板 | 按条板厚度、面密度、接缝密封给区间估算 | 粗略估算 | 不处理板缝施工缺陷导致的离散偏差 |
| 异质复合墙 | 可做趋势判断和敏感性分析 | 仅供方案比较 | 不输出单一精确 dB 值 |
| 极端隔声需求（Rw+Ctr ≥60 dB） | 识别双空腔、声桥、密封、低频短板风险 | 风险审查优先 | 不承诺达标，必须建议专项声学设计/检测 |

### 3.2 楼地面技能调用边界（撞击声隔声）

| 构造类型 | 可支持能力 | 输出等级 | 不得覆盖的范围 |
|---------|-----------|---------|---------------|
|  bare 楼板（无面层） | 基于楼板面密度的 Ln,w 基础估算 | 粗略估算 | 不替代实验室 Ln,w 检测 |
| 浮筑地面（弹性垫+面层） | 基于动态刚度的 ΔL 估算、撞击声改善趋势判断 | 专业估算 | 不处理垫层老化、施工不平整导致的离散偏差 |
| 架空地面（架空层+面板） | MSM 模型估算架空层对撞击声的衰减 | 专业估算 | 不处理架空层内管线穿透导致的声桥 |
| 地暖兼容地面 | 识别地暖层对隔声垫层的压缩风险 | 风险提示 | 不估算地暖运行后的隔声性能退化 |
| 极端改善需求（Ln,w ≤55 dB） | 识别多层复合、软木/橡胶垫、质量-弹簧系统的可行性 | 风险审查优先 | 不承诺达标，必须建议专项声学设计/检测 |

### 3.3 吊顶技能调用边界（隔声吊顶构造）

| 构造类型 | 可支持能力 | 输出等级 | 不得覆盖的范围 |
|---------|-----------|---------|---------------|
| 单层吊顶面板 | 基于面密度的质量定律估算、吻合效应风险提示 | 专业估算 | 不替代实验室 Rw 检测报告 |
| 双层吊顶（吊杆+面板+空腔） | MSM 模型估算、空腔增益判断 | 专业估算 | 不处理吊杆刚性传声、吊顶内机电噪声 |
| 隔声吊顶（独立吊顶+原顶空腔） | 双空腔增益、侧向传声风险提示 | 专业估算，需列关键假设 | 不保证侧向传声控制后的整体隔声量 |
| 极端隔声需求（Rw+C ≥55 dB） | 识别多层吊顶、弹性吊杆、严格密封的可行性 | 风险审查优先 | 不承诺达标，必须建议专项声学设计/检测 |

### 3.4 统一不可处理范围（所有调用方共享）

以下因素超出 ACE 模型能力，涉及这些因素时，ACE 必须提示需要现场检测或专项声学顾问复核：

1. 现场侧向传声（flanking transmission）
2. 门窗、检修口、穿墙套管等薄弱构件
3. 楼板/梁柱绕射
4. 复杂节点泄漏（如管道井、电梯井道）
5. 施工质量离散（板缝处理、密封连续性、吊杆紧固度）
6. 房间混响时间修正（现场测量时才涉及）
7. 已安装现场的实测替代判断
8. 结构振动噪声（如设备振动通过结构传声）

## 四、通用输入参数 Schema

> **设计原则**：ACE 的输入参数分为三层——调用方标识层、构造描述层、物理参数层。调用方标识层决定评价量和构造规则；构造描述层描述实际构造形式；物理参数层提供计算所需的数值。

### 4.1 通用输入结构（ACE-IN）

```json
{
  "调用方标识": {
    "技能标识": "string",      // 枚举：PW / FL / CL / ...
    "计算类型": "string",      // 枚举：空气声隔声 / 撞击声隔声
    "评价量": "string"         // 枚举：Rw+C / Rw+Ctr / DnT,w+C / Ln,w / ΔL
  },
  "构造描述": {
    "构造类型": "string",      // 枚举：单层均质 / 双层板+空腔 / 多层复合 / 浮筑 / 架空 / 条板
    "板材层": [
      {
        "材料类别": "string",  // 枚举：石膏板 / 耐火石膏板 / 硅酸钙板 / 纤维水泥板 / ALC / 混凝土空心条板 / GRC条板 / 发泡陶瓷条板 / 金属板 / 木饰面板 / 其他
        "厚度_mm": "number",
        "面密度_kg_m2": "number",  // 可选，缺失时由 ACE 根据材料+厚度推算
        "层数": "number"          // 同材料同厚度的层数，默认1
      }
    ],
    "空腔层": [
      {
        "深度_mm": "number",
        "填充材料": "string",    // 枚举：岩棉 / 玻璃棉 / 聚酯纤维棉 / 软木 / 橡胶 / 无 / 其他
        "填充率": "string"       // 枚举：满填 / 部分填充 / 无
      }
    ],
    "支撑/连接系统": {
      "支撑类型": "string",      // 枚举：轻钢龙骨 / 铝龙骨 / 木龙骨 / 吊杆 / 弹性吊杆 / 浮筑垫层 / 无(条板直接安装)
      "连接方式": "string",      // 枚举：刚性连接 / 弹性连接 / 解耦连接 / 浮筑隔离
      "龙骨间距_mm": "number",   // 可选
      "吊杆间距_mm": "number",   // 可选，吊顶场景
      "弹性垫动态刚度_MN_m3": "number"  // 可选，浮筑地面场景
    },
    "密封方式": "string"         // 枚举：MS密封胶 / 隔声密封条 / 普通密封 / 未指定
  },
  "计算选项": {
    "输出详细度": "string",      // 枚举：简略（仅区间）/ 标准（区间+风险）/ 详细（区间+风险+敏感性）
    "频率范围_Hz": {            // 可选，默认 100-3150
      "下限": "number",
      "上限": "number"
    }
  }
}
```

### 4.2 各调用方的最小参数集

| 调用方 | 最小必填参数 | 选填参数 |
|--------|------------|---------|
| **隔墙（PW）** | 板材层（材料+厚度+面密度或材料+厚度）、空腔层（深度）、支撑类型、连接方式、评价量 | 填充材料、密封方式、龙骨间距 |
| **楼地面（FL）** | 楼板基层（材料+厚度+面密度）、面层/垫层（材料+厚度）、评价量（Ln,w 或 ΔL） | 弹性垫动态刚度、浮筑构造描述 |
| **吊顶（CL）** | 吊顶面板（材料+厚度+面密度或材料+厚度）、空腔深度、吊杆类型、评价量 | 填充材料、吊杆间距、密封方式 |

      "优化方向": ["string"]
    }
  },
  "敏感性分析": {                  // 仅在详细输出时提供
    "关键参数": [
      {
        "参数名": "string",
        "当前值": "string",
        "变化影响": "string",      // 如：面密度+20% → Rw+1.5dB

  },

### 5.2 输出降级规则

| 场景 | ACE 输出行为 |
|------|-------------|

### 6.1 IC-03：隔墙技能 → ACE（空气声隔声）

已在 `interface-contracts.md` v1.2 中定义。本文件对其进行通用化扩展说明：

- **调用方标识**：技能标识 = PW，计算类型 = 空气声隔声
- **评价量**：Rw+C / Rw+Ctr / DnT,w+C（由隔墙技能基于 A1 表确定）

## 七、新增技能接入 ACE 的流程

当新的子技能需要接入 ACE 时，须按以下流程完成接口实例化：

```
第1步：评估接入必要性
  └─ 确认该技能是否涉及隔声/隔振计算需求
  └─ 确认现有 ACE 通用模型是否可覆盖（或需扩展）

第2步：定义评价量和构造特征
  └─ 确定该技能使用的隔声/隔振评价量（如新增 Dn,e,w 等）
  └─ 梳理该技能典型构造形式和关键参数

第3步：申请接口契约编号
  └─ 在 interface-contracts.md 中申请新的 IC-XX 编号
  └─ 按 ACE-IN/ACE-OUT 通用 Schema 实例化该技能的输入输出字段

第4步：评估模型扩展需求
  └─ 如需新增物理模型（如新增隔振模型），须在 ACE 架构文档中补充模型定义
  └─ 如需新增材料参数，须在 ACE 材料参数库中补充条目

第5步：定义适用边界
  └─ 按第三节格式，补充该技能的适用边界表
  └─ 明确不可处理范围和输出等级

第6步：复核确认
  └─ 提交 prefab-standards-reviewer 复核接口契约
  └─ 提交 skill-qa-tester 设计 mock 校验用例
  └─ 更新 interface-contracts.md 注册表总览和变更日志
```

## 八、不可处理范围与降级策略

### 8.1 统一不可处理范围（所有调用方共享）

ACE 在以下场景下不得输出确定数值，只能返回风险提示和人工评估建议：

| 编号 | 不可处理因素 | 触发条件 | ACE 输出 |
|------|------------|---------|---------|
| U-01 | 现场侧向传声 | 任何构造类型 | "现场侧向传声未纳入模型，实际隔声量可能低于估算值 5-15 dB" |
| U-02 | 门窗/检修口等薄弱构件 | 构造描述中提及门窗或开口 | "开口和薄弱构件显著降低整体隔声，需专项设计" |
| U-03 | 施工质量离散 | 任何估算场景 | "计算基于理想构造模型，实际施工质量可能导致 ±3-8 dB 离散" |
| U-04 | 结构振动噪声 | 用户提及设备振动/结构传声 | "结构振动噪声超出 ACE 空气声隔声模型范围，建议结构声学顾问复核" |
| U-05 | 已安装现场实测 | 用户要求以实测值替代估算 | "ACE 输出为专业估算，不替代现场实测；实测值与估算值差异属正常" |
| U-06 | 信息不足输入 | 关键参数缺失且无法典型值推算 | "参数不足，列出缺失字段：[字段列表]" |
| U-07 | 极端构造超出经验范围 | 构造形式不在适用边界表中 | "超出 ACE 模型适用范围，建议专项声学设计" |
| U-08 | 复杂节点泄漏 | 涉及管道井、电梯井道等 | "复杂节点泄漏未纳入模型，需专项密封设计" |

### 8.2 调用失败降级策略

| 异常情况 | 降级策略 | 输出标注 |
|---------|---------|---------|
| ACE 调用失败 | 调用方使用自身 reference.md 中的简化计算方法论执行基础估算 | "简化估算（隔声计算引擎暂不可用）" |
| ACE 返回参数不足 | 调用方向用户追问缺失参数，或基于已知参数给出原则性分析 | "关键参数缺失，以下为基于部分信息的参考分析" |
| ACE 返回超出范围 | 调用方保留 ACE 的风险提示，并建议用户咨询专项声学顾问 | "超出模型适用范围，以下风险点须人工评估" |

## 九、评价量与构造规则对照表

| 评价量 | 定义 | 适用场景 | 对应技能 | 强制性标准 |
|--------|------|---------|---------|-----------|
| **Rw+C** | 实验室空气声隔声单值评价量 + 粉红噪声频谱修正 | 中高频隔声评价（办公室、教室、客房之间） | 隔墙、吊顶 | GB/T 50121-2005 |
| **Rw+Ctr** | 实验室空气声隔声单值评价量 + 交通噪声频谱修正 | 低频隔声评价（噪声机房、设备间、交通噪声场景） | 隔墙、吊顶 | GB/T 50121-2005 |
| **DnT,w+C** | 现场空气声隔声单值评价量 + 粉红噪声修正 | 现场验收指标（住宅分户墙强制） | 隔墙 | GB 55038-2025（住宅） |
| **Ln,w** | 标准化撞击声压级 | 楼地面撞击声评价（实验室） | 楼地面 | GB/T 50121-2005 |
| **ΔL** | 撞击声改善量 | 楼地面面层/垫层的撞击声改善评价 | 楼地面 | GB/T 50121-2005 |
| **Ln,T,w** | 现场标准化撞击声压级 | 楼地面撞击声现场验收 | 楼地面 | — |

> **重要说明**：不同评价量之间不可直接换算。ACE 的输出须严格标注评价量，调用方不得混用。例如：Rw+C（实验室）≠ DnT,w+C（现场），现场指标通常比实验室低 5-10 dB。

## 十、与 interface-contracts.md 的协同关系

| 本文件内容 | 对应 interface-contracts.md 章节 | 协同规则 |
|-----------|--------------------------------|---------|
| 通用输入 Schema（ACE-IN） | IC-03/IC-08/IC-09 请求参数 | 本文件定义通用 Schema，interface-contracts.md 中各 IC 做字段级实例化 |
| 通用输出 Schema（ACE-OUT） | IC-03/IC-08/IC-09 响应参数 | 同上 |

**变更同步规则**：
- 当 ACE 通用 Schema 发生变更时，须同步更新 interface-contracts.md 中所有相关 IC
- 当新增技能接入 ACE 时，须同时更新本文件（适用边界表）和 interface-contracts.md（新增 IC）
- 当新增物理模型或材料参数时，须更新本文件和 ACE 的 reference.md
