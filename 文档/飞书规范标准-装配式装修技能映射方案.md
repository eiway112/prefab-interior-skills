## 规范标准知识管理 × 装配式装修技能 — 架构感知映射方案

> 最后更新：2026-06-12
>
> **基本准则：开放性。** 技能合集是面向开放应用的自包含知识系统，不依赖任何单一外部平台（包括飞书）的账号权限、API 可用性或个人数据。所有标准知识在建仓后以本地文件形式存在，任何协作者均可参与维护和更新。
>
> 设计原则：规范标准按照"部品系统 + 材料 + 通用"的逻辑分层组织，映射到技能合集时必须尊重 L0/L1/L2 的既有架构，每条标准有且仅有一个"归属层"。飞书云盘作为个人开发阶段的便利入口保留映射关系，但不是系统的唯一知识源头。

---

### 〇、系统边界定义（红线）

**本系统是"装配式装修系统"**，覆盖装配式内装修的部品系统（隔墙、墙面、吊顶、楼地面、厨卫、收纳）、机电集成、验收和质量控制。

以下领域是**独立的平行体系**，不属于装配式装修系统的范畴，**严禁纳入本系统**：

| 参考来源（个人飞书） | 独立体系 | 不纳入原因 |
|---|---|---|
| 05-绿色建筑&建材/ | 绿色建筑评价体系 | 绿色建筑是覆盖建筑全生命周期的独立评价系统，装配式装修只是其中一个得分项 |
| 06-适老化/ | 适老化/无障碍设计体系 | 适老化是跨建筑类型的独立设计规范体系，与装配式装修是交叉关系而非包含关系 |
| 09-智能建造/ | 智能建造技术体系 | 智能建造涵盖 BIM、机器人、数字化管理等独立技术栈，远超装配式装修的边界 |
| 10-既有建筑改造/ | 既有建筑改造技术体系 | 既有建筑改造涉及结构加固、设备更新等独立专业领域 |

这些文件夹保留在飞书云盘中作为**个人知识库**，但与装配式装修技能合集无关。如果未来需要开发这些领域的技能，应当作为**独立的技能合集**而非本系统的子模块。

### 三、数据流设计

#### 3.1 标准知识入库流（平台无关）

标准知识从权威源头进入技能合集的完整流程，不依赖任何特定平台。

```
权威源头（国家标准全文公开系统 / 住建部官网 / 各省市住建厅等）
      │
      │  ① 获取标准原文（PDF / 公开全文）
      ▼
建仓标准库（shared/standards-pdf/）
      │  PDF 原文归档到技能合集仓库，成为自包含资产
      │
      │  ② 提取关键技术指标
      ▼
本地知识库（standards-index.md + 各技能 reference.md）
      │
      │  ③ standards-reviewer 复核
      ▼
部署到技能合集（运行时自包含，不依赖外部平台）
```

**飞书作为可选入口**：个人开发阶段，可以从飞书云盘下载 PDF 作为获取标准原文的便捷方式。但 PDF 一旦下载即归档到建仓标准库，后续维护不再依赖飞书。其他协作者可以通过国家标准全文公开系统等公开渠道获取同一标准原文。

#### 3.2 标准更新监控流（平台无关）

标准更新的监控基于公开发布渠道，不依赖个人飞书账号权限。

```
国家标准全文公开系统（openstd.samr.gov.cn）发布公告
      │
      │  定期监控（可用定时任务，任何人均可执行）
      ▼
识别新发布/修订/废止的标准编号
      │
      │  对比 standards-index.md 中的版本记录
      ▼
触发 standards-reviewer 复核 → 更新技能文件 → 遵循 change-governance.md 变更流程
```

**飞书监控（可选辅助）**：个人开发阶段，可以同时监控飞书云盘文件变化作为辅助提醒。但这不是系统的主监控通道——主通道始终是基于公开发布渠道。

#### 3.3 归属冲突仲裁

当一条标准同时关联多个部品技能时：

1. **材料产品标准**（如 GB/T 9775 纸面石膏板）→ 归 materials-expert，部品技能通过协同路由引用
2. **综合技术标准**（如 DB11/T 1553 北京地标）→ 各部品技能各自引用与本系统相关的条文
3. **接口标准**（如 DB4401/T 236 设备与管线）→ 归 mep-integration，部品技能通过协同路由引用

#### 3.4 建仓标准库目录规划

建仓后，标准 PDF 原文按归属层组织在仓库内，所有协作者均可访问：

```
shared/standards-pdf/
├── mandatory/（强制性国标）
│   ├── GB-55037-2022.pdf
│   ├── GB-55038-2025.pdf
│   └── ...
├── recommended/（推荐性标准）
│   ├── GB-T-50121-2005.pdf
│   ├── JGJ-T-491-2021.pdf
│   └── ...
├── atlas/（图集）
│   ├── 07CJ03-1.pdf
│   └── ...
├── product/（产品标准）
│   ├── GB-T-23451-2023.pdf
│   └── ...
└── local/（地方标准，按省市分子目录）
    ├── beijing/
    ├── guangdong/
    └── ...
```

> **文件命名规则**：`[标准编号]-[年份].pdf`，编号中的 `/` 替换为 `-`，空格去除。例如 `GB/T 50121-2005` → `GB-T-50121-2005.pdf`。
>
> **版权合规**：部分标准受版权保护，建仓时须确认分发权限。对于不可公开分发的标准，在 standards-index.md 中标注"版权受限，PDF 不随仓库分发"，并提供权威源头的公开获取链接。

### 四、实施优先级

**P0（立即执行）**：补强 standards-index.md

将强制性国标和装配式装修总纲性标准纳入策划版 standards-index.md。策划版已有 42 条标准，对照标准原文验证编号和状态准确性。标准原文优先从国家标准全文公开系统获取，个人飞书云盘中的 PDF 可作为快速对照。

**P1（隔墙技能优先）**：填充 partition-wall 的标准引用

隔墙技能是当前最成熟的部品技能。获取隔墙专属的标准 PDF（来源：国家标准全文公开系统、住建部官网、或个人飞书云盘），提取关键技术指标（隔声、耐火、尺寸偏差），补充到隔墙技能的 reference.md 中，同时将 PDF 原文归档到建仓标准库。

**P2（成熟部品技能）**：依次填充 wall-surface、其他部品技能

按部品技能的成熟度排序，逐步将归属该技能的标准纳入。

**P3（骨架技能激活）**：ceiling、floor、bathroom-kitchen、storage

这些技能当前只有骨架。获取归属标准后，先用标准内容填充 reference.md 的基础框架，再逐步丰富。

**P4（预留模块）**：评价、绿色建筑、适老化等

这些领域暂不处理，但建立索引清单（标准编号 + 公开获取链接），为未来技能开发提供快速定位。
