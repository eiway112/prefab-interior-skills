- **归一化**（唯一口径，两侧同法）：去所有空白、全角破折号 `—`→`-`、全角斜杠 `／`→`/`、转大写。**词典匹配按键长度降序做最长匹配**，防止 `JG/T 578` 被 `JG/T 5` 截断。

### 3.2 取数口径（三类载体，逐类给可核样例）

| 载体 | 提取规则 | 锚（binding）来源 | 真实命中例（现测 PASS） |
|---|---|---|---|
| ① 散文形 | 关键字 `索引序号｜序号`（长式优先，防「索引序号」被「序号」重复计一次）＋**声明串** | 同一行内该声明**之前**的文本 ＋（若该行是表行）同行其余单元 → 词典最长匹配所得编号集合 | `prefab-ceiling-system/reference.md:214`「GB 8624-2012《…》（standards-index 序号 42，现行有效）」→ 42∈{GB 8624 的序号 42} |
| ② 表列形 | 表头含「索引序号」的列，单元内**每一个**数字为一个判定单元 | **同行其余全部单元**（结构绑定，无跨行歧义） | `prefab-wall-surface-system/SKILL.md:526`「\| GB 55037-2022《建筑防火通用规范》 \| 防火强制性总纲 \| **2** \| …」 |
| ③ 内联形 | 同 `序号` 的声明串式，关键字为 `索引\s*#` | 同行该声明之前 ＋ 之后各 220 字符 | `prefab-wall-surface-system/examples.md:31`「T/CECS 1018-2022 … 索引#31」 |

**声明串 → 判定值的展开规则（F8 的正面口径，实施批须逐字照此实现）**。声明串字面（①③ 共用）：
`(?P<first>\d+)(?P<rest>(?:\s*(?:[/、，,]|及|和|或|[-－~～]|至|到)\s*\d+)*)`

1. **并列分隔符** `[/、，,]|及|和|或` → 逐个值各自进判据（`9/10/32/33/34` → 5 个判定单元）。
2. **区间分隔符** `[-－~～]|至|到` → **仅当左值 < 右值且跨度 ≤ 60** 才展开为区间内全部序号（69 条上界，故合理区间必在此内）；不满足即**整串不拆**、按 `EXEMPT` 计数披露（E6）。该条件正是把 `序号44-1`（用例条目号，44>1）与 `11-13`（真区间）分开的结构判据——不靠行号、不靠白名单。
3. 展开后每个值**独立**按 §4.1 成员判据判定；一行内任一值为 `DRIFT` 即整条 FAIL，INFO 须带**该值的位置序号**（第 N 值），否则实施者无法定位是并列串里的哪一格错。

**同一位置的载体归属优先级：② > ①**（一行既是「索引序号」表行又含散文「序号 N」时，② 判其数值单元、① 不重复判该行），防止一个单元被两条规则各判一次造成 OK 行虚增。**③ 与 ①② 互斥**（`索引#N` 不含「序号」字面）。

## 4. 判据

### 4.1 核心判据：成员判据，不是最近邻判据

对判定单元 `(声明值 v, 锚集合 C)`：

```
S = ⋃_{c ∈ C} code2seq[c]          # 锚编号在索引中的序号集合
若 C 为空          → NO-ANCHOR（不判，INFO 逐条披露）
否则若 v ∈ S       → PASS
否则               → DRIFT（报红）
```

**为什么是成员而不是精确配对**：F3（多编号并列）证明「一个声明附近常有多个合法编号」，最近邻绑错必产假红；而成员判据在锚集内不指定唯一配对，代价是**「把序号写成同窗口内另一标准的序号」抓不到**（如 :197 若误写「序号 2」则 PASS）。此为**有意的取舍**，须写入 §11.3 披露，不是遗漏。反向注入仍然有效——注入一个**不在**锚集内的序号（本文实测注入 44、9、31 三种）必报红。

### 4.2 豁免规则：一律取**结构判据**，不建白名单

| 规则 | 表达形式 | 为什么不是白名单 |
|---|---|---|
| E1 无锚不判 | 判定单元所在窗口内**词典零命中** → `NO-ANCHOR` | 现测吸收 **10 个判定值／4 个位置**（`SKILL.md:541`、`reference.md:141` 各 2 值＝序号 54/69 哨兵行；`examples.md:40` 1 值；`reference.md:145` 5 值），无需逐处登记文件行号；白名单会随技能正文漂移且需人工维护（违 P2） |
| E2 `原序号` 免自匹配 | 提取阶段用**否定后顾 `(?<!原)`**，不做事后排除 | 上一线的追溯注记是裁定产物，须永久免判；写在正则里而非名单里，故新增一处注记不需改守卫。现测 **11 处**（F4 表列 5 处＋表行内／其余 6 处，见 §12） |

### 12.2 参考实现（探测件核心，**非交付代码**；实施批须与之逐条对齐后落在 `程序文件/`）

本轮全部读数出自 `D:/Qoder-Files/_tmp-scripts/` 下的一次性探测件（probe4／probe6／probe7），**不在 git 内、不随仓推送**，故把判据内核内联于此供实施批对照，避免「设计说一套、实施另写一套」：

```python
LIST_SEP  = r"[/、，,]|及|和|或"        # 并列 → 逐值进判据
RANGE_SEP = r"[-－~～]|至|到"            # 区间 → 仅升序合理才展开
SEPS = "(?:%s|%s)" % (LIST_SEP, RANGE_SEP)
TAIL = re.compile(r"(?P<first>\d+)(?P<rest>(?:\s*%s\s*\d+)*)" % SEPS)
KEY   = re.compile(r"(索引\s*序号|索引\s*#|序号)")     # 长式优先
INT  = re.compile(r"(?:表|附录|图)\s*[\d.]+[^\d]{0,12}$|第\s*[\d.]+\s*条\s*$")  # E3，与载体无关

def expand(seg):                                        # 声明串 → 判定值列表
    out = [seg.group("first")]; prev = int(out[0])
    for sep, nxt in re.findall(r"(%s)\s*(\d+)" % SEPS, seg.group("rest")):
        if re.fullmatch(RANGE_SEP, sep.strip()):
            a, b = prev, int(nxt)
            if not (a < b <= a + 60): return [], "EXEMPT-E6"   # 44-1 落此
            out += [str(k) for k in range(a + 1, b + 1)]
        else: out.append(nxt)
        prev = int(nxt)
    return out, None

def judge(anchors, v):                                  # §4.1 成员判据
    if not anchors: return "NO-ANCHOR"                  # E1
    seqs = set(sum((code2seq.get(a, []) for a in anchors), []))
    return "PASS" if v in seqs else "DRIFT"
```

两侧词典与真值表口径见 §3.1；`codes()` ＝ 归一化后按键长度降序最长匹配。
