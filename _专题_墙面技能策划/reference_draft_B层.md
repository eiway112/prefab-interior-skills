## B1：选型决策树

### Step 1 — 场景识别

```
用户输入
  ├── 空间类型：住宅 / 酒店 / 医院 / 学校 / 办公 / 厨卫湿区？
  ├── 基层状况：基层类型（混凝土/砌体/加气块/隔墙基层板）+ 平整度？
  ├── 管线需求：无 / 扁平线槽 / 标准线管（Φ20）？
  ├── 性能诉求：防火等级 / 环保 / 抗菌 / 耐撞击 / 美观 / 可检修？
  └── 认定诉求：是否参与装配率评价（→ 触发 B3 判定）？
```

### Step 2 — 硬约束筛查（逐条过筛，任一命中即收窄路线）

| 硬约束 | 判据 | 收窄结果 | 依据 |
|--------|------|---------|------|
| 基层平整度 | ≤3mm | 可选干法直挂/无龙骨点式调平 | A4.1〔S2·广州市汇编〕 |
| 基层平整度 | >3mm（无调平） | 必须龙骨调平或先行找平 | A4.1 |
| 管线分离 | 需走标准线管（Φ20） | LGS 工法（空腔 50-130mm+） | A4.3 |
| 管线分离 | 仅扁平线槽 | UL 工法或挂粘式I（含管线分离 50mm 版） | A4.3、A1.5 |
| 湿区 | 厨房/卫生间墙板 | JG/T 533-2018 湿区墙板路线 + 防水界面协同 waterproofing-expert | 索引序号 41、§B5 |
| 防火 | A 级要求（医院/学校等） | 无机基材体系（硅酸钙/硅晶/铝蜂窝） | A2.1、A1.7 |
| 频繁检修 | 机电检修口密集部位 | 磁吸式或干挂式（可逆拆装） | A4.2 |
| 装配率认定 | 需计入装配式墙面面积 | 排除涂料饰面；壁纸须免腻子工艺 | B3 |
| 吊挂荷载 | 电视/空调/热水器等重物 | 预埋加固板（按 A1.6 表） | A1.6 |

### Step 3 — 技术路线匹配

三大技术路线总览（详见 A4.3 工法原理）：

| 技术路线 | 空腔 | 管线分离能力 | 典型场景 |
|---------|------|------------|---------|
| 无龙骨点式调平 | 0-10mm | 受限（预埋） | 基层平整度高、商业大板 |
| 龙骨调平（GL/UL/LGS） | 20-130mm+ | 好→最优 | 住宅、酒店、医院主流 |
| 干法直挂 | 40-60mm+ | 好（可拆卸） | 高端、频繁检修部位 |

> 注：干法直挂在部分汇编分类中亦指饰面板直接挂装于基层（厚度 4mm 级、无空腔，见 A1.5 挂粘式直挂墙面），选型时以具体产品的构造参数为准。

**场景化推荐基线**（须再经 B2 验证方可输出）：

| 场景 | 推荐方向 | 关键判据 |
|------|---------|---------|
| 医院 | 无机洁净板（硅酸钙/金属板）、挂钩或卡扣可拆装连接、阳角圆角 | A1.7 医院表、B4 医疗专项 |
| 学校 | 耐撞击、耐划痕体系 | A1.7 学校表 |
| 酒店 | 质感优先（硅晶/包覆型）、耐污染高端档 | A1.7 酒店表 |
| 住宅 | 集成墙面（认定导向）、龙骨调平+管线分离 | B3 认定规则 |
| 厨卫湿区 | JG/T 533-2018 路线墙板，防水界面先行 | §B5、waterproofing-expert |

### Step 4 — 性能核验（进入 B2）

选型候选确定后，**必须**执行 B2 验证协议六步流程，禁止跳过验证直接输出选型结论（拟注册红线 WS-R-P0-4）。

### Step 5 — 输出组装

按 SKILL.md 输出模板结构化输出，含验证记录段与免责声明（B2 Step 5）。

## B2：验证协议（六步执行清单，WS 特化版）

> WS 域无隔声计算职能，B2 为**数据核验型**验证（非物理计算型，区别于 FL/PW 的 ACE 调用）。验证证据分级沿用 A 层"来源分级说明"（S1-S4）。

### Step 0：标准推理（SRE，IC-10）

- 调用 standards-reasoning-rules（IC-10）按"项目类型 × 空间类型 × 项目所在地"激活适用标准集：
  - 医院病房/手术部墙面 → fire, environmental, acceptance, prefab
  - 酒店客房墙面 → acceptance, prefab, acoustic(边界提示)
  - 住宅户内墙面 → prefab(认定), acceptance, environmental
  - 学校教室墙面 → fire, environmental, acceptance
  - 厨卫湿区墙板 → prefab, waterproof(外部协同), acceptance
- 地方评价标准族按项目所在地激活（DB11/T 1553-2025、SJG 159-2024、DB33/T 1259-2021 等）。
- **禁止跳过本步**直接引用记忆中的标准（拟注册红线 WS-R-P1-5）。

### Step 1：输入解析

解析并确认：建筑类型、空间类型、基层墙体（类型+平整度）、管线需求、湿区/干区、认定诉求、项目所在地。输入缺失关键项（如项目所在地影响地方标准激活）时，先向用户澄清，不得假设默认值。

### Step 2：三原则审查

| 原则 | 审查内容 | 失败处置 |
|------|---------|---------|
| 场景匹配 | 候选体系是否匹配空间功能与性能诉求（对照 A1.7 场景表） | 回到 B1 Step 3 重选 |
| 标准时效性 | 引用标准是否现行有效；GB 8624 以 2012 版为现行（2025 版 2027-01-01 实施前不得替代）；地方标准标注年份与修订状态 | 更正版本；无法确认时效→标注"待核验" |
| 装配式认定边界 | 饰面做法是否具备认定资格（涂料排除、壁纸须免腻子，见 B3） | 明确告知不认定风险 |

### Step 3：性能核验（数据核验型）

| 核验项 | 判据锚点 | 输出要求 |
|--------|---------|---------|
| 防火等级 | A2（GB 8624 现行版分级 + 场景要求） | 给出等级 + 检测依据标准 + 来源分级 |
| 环保限值 | A3（甲醛 GB 18580/GB·T 39600、TVOC、放射性 GB 6566） | 限值 + 实测值（如有，S2）+ 来源分级 |
| 验收偏差 | A5.1 三表（按验收对象选表，不可混用） | 明确选用哪张表及理由 |
| 装配率认定 | B3 判定流程 | 认定结论 + 依据的地方标准（含年份） |

### Step 4：N 维度核验

- D1 防火｜D2 环保｜D3 平整度与调平｜D4 空腔与管线｜D5 湿区防水界面｜D6 认定与装配率｜D7 与隔墙系统边界
- D7 要点：隔声/耐火问题是否误入本技能（命中则路由 prefab-partition-wall-solution，红线 WS-R-P0-2）；隔墙基层板交接面是否明确（A4.5）。
- 任一维度 FAIL：输出 FAIL 项与整改建议，不得拼装完整推荐结论。

### Step 5：输出组装

按 SKILL.md 输出模板结构化输出，必须包含：选型结论、**验证记录段**（下表字段）、免责声明。

**验证记录段格式**：

| 字段 | 内容 |
|------|------|
| 输入摘要 | 建筑/空间/基层/管线/认定诉求 |
| 适用标准集 | Step 0 激活清单（含序号与状态） |
| 核验结论 | 各维度 PASS/WARN/FAIL |
| 证据分级 | 关键数据的 S1-S4 标注 |
| 未决事项 | 待核验条文号、待补录标准、需用户澄清项 |

### 附：未收录标准的运行时核验程序（遇缺即录闭环）

当任务需要引用 standards-index **未收录**的标准时，按以下顺序处理：

1. **查库**：先查 standards-index.md 与所属技能 reference 的标准清单，确认确未收录。
2. **官方平台核验**：按优先级查证——国家标准全文公开系统（openstd.samr.gov.cn）→ 全国标准信息公共服务平台（std.samr.gov.cn）→ 住建部及地方住建厅官网公告。确认编号、年份、实施日期、现行/废止状态。
3. **可核验**：引用时标注标准全称 + 核验状态；同时在输出的"未决事项"中登记补录建议（入库层级建议：WS 域 / materials-expert 域 / 合集级），由 change-governance B 类变更流程补录入 standards-index。
4. **不可核验**（无官方来源，如部分团体标准、内部导则）：只允许以"标准名称+章节主题"方式引用，**标注"未核验，不作为合规判据"**，禁止输出具体条文号与确定性限值。
5. **禁止项**：不得凭记忆补全未核验标准的条文号、年份或限值；不得将未核验标准作为唯一合规依据。

## B3：装配率认定判定

> 本模块为 WS 域特有高频决策点。所有认定数据**必须标注所属标准与年份**（各地标准持续修订，拟注册红线 WS-R-P2-3 兜底时效性标注）。

### B3.1 通用认定三要素

各地方标准对"装配式墙面"的认定均需同时满足三个条件：

1. **集成化设计**（与管线、开关插座、吊顶、地面等一体化设计）
2. **工厂化生产**（部品部件在工厂预制完成）
3. **干式工法施工**（现场采用干作业施工工艺）

### B3.2 饰面做法认定判定表

来源：S1·中国房地产业协会标准 条文说明 表2（该标准未发布，引用时须标注状态）

| 基层构造 | 饰面做法 | 是否认定为装配式墙面 |
|---------|---------|-------------------|
| 龙骨架空形式 | 一体化饰面板 | **符合** |
| 龙骨架空形式 | 免腻子+壁纸（壁布） | **符合** |
| 龙骨架空形式 | 基层板+一体化饰面板 | **符合** |
| 龙骨架空形式 | **涂料饰面** | **不符合** |
| 基点调平形式 | 一体化饰面板 | **符合** |
| 基点调平形式 | 免腻子+壁纸（壁布） | **符合** |
| 基点调平形式 | 基层板+一体化饰面板 | **符合** |
| 基点调平形式 | **涂料饰面** | **不符合** |

> **关键结论**：涂料饰面无论搭配何种基层构造，均不被认定为装配式墙面。壁纸（壁布）仅在"免腻子"前提下可认定。

### B3.3 判定流程

```
用户饰面做法
  ├── 涂料饰面？ ── 是 → 不符合认定（无论基层构造）→ 告知风险并给出可认定的替代方案
  ├── 壁纸/壁布？ ── 是否免腻子工艺？
  │       ├── 是 → 符合（须基层为龙骨架空/基点调平形式）
  │       └── 否 → 不符合
  ├── 一体化饰面板/基层板+一体化饰面板？ ── 是 → 符合
  └── 薄贴瓷砖类？ ── 查项目所在地标准：
          ├── 深圳：湿作业抹灰基层不计入；基层平整度≤4mm/2m 时按 0.5 系数〔SJG 159-2024〕
          ├── 河南/广州/福建等：按当地系数与扣除规则（见 B3.5）
          └── 未明确地区：标注"当地标准未明确，建议咨询当地主管部门"
```

### B3.4 地方特殊规定

**深圳市（SJG 159-2024）**〔S1·地方标准〕：

- **双条件缺一不可**："需同时满足工厂生产、现场干式工法施工两个条件才能认定为装配式装修"
- **明确排除**："墙面薄贴前进行湿作业抹灰的不计入装配式墙面面积"
- **合格材料清单**：金属集成板、竹（木）塑集成板、石塑集成板、陶瓷集成板、木质集成板、自饰面硅酸钙板、纤维增强水泥装饰板等
- **硬包排除示例**："以传统装修工程中的硬包安装为例，虽然满足干式工法要求，但若硬包为现场通过裁切、涂胶、包覆等流程制作而成，不满足工厂生产要求，则不被认定为装配式装修工艺"

**河南省导则（2024）逐房间认定标准**〔S1·地方导则〕：

| 空间 | 合格的装配式墙面做法 |
|------|-------------------|
| 客厅/餐厅/卧室 | 集成板材墙面（金属集成板、竹木纤维板、石塑集成板、陶瓷集成板、木质集成板、无机类集成板）；成品模块墙面（金属制品、矿棉制品、石膏制品免腻子、玻璃制品、石材/瓷砖干挂、饰面有机物人造板、硫镁板） |
| 厨房 | 仅"工厂预制、现场干法施工、瓷砖复合壁板模块化墙面" |
| 卫生间 | 彩钢板型/瓷砖型/岩板型聚氨酯发泡壁板、SPC饰面硫镁板复合壁板、SMC壁板 |

## B4：施工控制

> 本节仅收录 v1.2.0 基线已持有的施工约束；各工法施工工艺细化参数（如粘结剂配比、龙骨间距）待阶段 7/8 依据 JGJ/T 491-2021 施工章节等原文核验后补充，补充前不得输出。

### B4.1 工法施工约束（源自基线的已知局限与要求）

| 工法 | 施工控制要点 | 依据 |
|------|------------|------|
| GL | 敲击有空鼓声为已知现象（交付前应向业主说明）；隔声低于龙骨法，有隔声诉求部位慎用；无法管线分离，管线须预埋或明装线槽 | A4.3 |
| UL | 弹性粘接剂对基层清洁度要求高（基层清理为关键工序）；成本高于GL，预算敏感项目比选 | A4.3 |
| LGS | 接线盒须固定在横龙骨上；如与竖龙骨冲突，须增设附加横龙骨固定 | 北京市导则 第5.2.4条〔S1·条文号待核验〕 |
| 磁吸式 | 柔性磁条须预贴于硅酸钙饰面板背面；单层/双层隔声耐火数据为行业测试值（S2），不作正式认定 | A4.2 |
| 直挂类（石晶/铝蜂窝） | 基层平整度≤3mm 为前置条件，超标先找平；重物吊挂预埋加固板 | A4.1、A1.6 |

### B4.2 医疗专项施工控制

**TCSUS 03-2019 墙面系统设计/施工要求**〔S1·团体标准，待官方核验〕：

- 面板宜采用金属、玻璃纤维增强石膏(GRG)、硅酸钙板、玻璃等无机环保材料
- 有洁净要求的区域宜采用金属洁净板，相邻面板间密拼处理
- 龙骨与面板应采用挂钩式连接或卡扣式连接，且具备重复拆装功能
- 单一模块应可单独拆卸
- 阳角部品宜做成圆角，圆角半径不小于20mm
- 分室隔墙宜采用双空腔结构

**一体化医疗设备带**〔S1·TCSUS 03-2019〕：

- 病房、产房等区域的医疗设备带宜集成设计嵌入墙体
- 设备带面板应与墙体齐平，并有可开启的装置
- 诊室等区域的观片灯、叫号机等宜集成设计嵌入墙体

**TCSUS 48-2022 既有医疗建筑改造要求**〔S1·团体标准，待官方核验〕：

- 预制复合墙体（板）由金属、玻璃、无机板等面板，钢制龙骨，填充材料，门窗，一体化医疗设备带，一体化墙柜及相应五金配件组成，包含单空腔、双空腔墙体和墙面（板）
- 墙面厚度控制：见 A4.4（<40mm / <60mm / <90mm 三工况）
- 有推床（车）通过的门和墙面，宜设置墙柱护角、墙面防撞带、防撞扶手
- 相邻装饰面板间密拼或留缝处理，留缝时采用成品软性材料密封，满足气密性及感染防控要求
- 踢脚线与墙面应齐平或内凹，不应凸出墙面
- PVC地胶板向上延伸至墙面时，踢脚线高度不宜小于100mm

## B5：管线分离

### B5.1 各技术路线管线分离方案

来源：S1·北京市导则（第6.2.4条框架，条文号待核验）+ 各路线构造参数（A4.3）

| 技术路线 | 管线敷设方式 | 空腔/线槽要求 | 适用管线类型 |
|---------|------------|-------------|------------|
| 板材隔墙 | 工厂预制线槽（槽深≤20mm） | 板内预埋 | 电线管、给水管（小口径） |
| 骨架隔墙 | 墙体空腔内走线 | 空腔≥50mm | 电线管、给排水管、暖通管道 |
| 集成隔墙 | 工厂预装管线和点位 | 模块内含 | 全类型（工厂集成） |
| 调平龙骨墙面 | 墙面与结构之间的空腔 | 空腔30-130mm | 电线管、扁平线槽 |
| 无龙骨点式 | 基层预埋或明装线槽 | 预埋深度≤20mm | 电线管（受限） |

### B5.2 管线分离设计要点

1. **T/CECS 1018-2022 第3.0.2条**〔S1·条文号 2026-08-05 核验〕：系统应满足部品检修更换、管线使用维护的要求，并应采用管线与结构分离技术
2. **北京市导则 第3.0.3条**〔S1·条文号待核验〕：设备管线与结构分离原则，满足室内设备和管线的维修需要
3. **北京市导则 第6.2.4条**〔S1·条文号待核验〕：
   - 板材隔墙管线在预制槽内
   - 骨架隔墙管线在墙体空腔内
   - 集成隔墙管线和点位在工厂预装
   - 调平龙骨墙面管线在墙面与结构之间的空腔内
   - 绝缘导线/电缆宜采用扁平线槽
4. **北京市导则 第5.2.4条**〔S1·条文号待核验〕：接线盒须固定在横龙骨上；如与竖龙骨冲突，须增设附加横龙骨固定

### B5.3 跨技能接口

- 管线综合、冲突识别、检修路径规划等机电集成问题路由至 prefab-mep-integration-system。
- 涉及隔墙空腔内管线（骨架隔墙/集成隔墙行）时，管线与隔声/耐火的相互影响属隔墙技能职能，WS 仅负责饰面侧空腔（调平龙骨墙面行）。

## 六、知识域：边界、协同与案例

> 本章为 WS 域的关系型知识（跨技能边界、协同规则、案例参考），供路由与集成校验使用。

### 6.1 与隔墙系统的技术边界

**边界定义**：隔墙系统的终止界面 = 墙面系统的起始界面。

| 系统 | 责任范围 | 终止/起始界面 |
|------|---------|-------------|
| 装配式隔墙系统 | 结构支撑、隔声、耐火、空腔管线 | 止于基层板（石膏板/硅酸钙板）外表面 |
| 装配式墙面系统 | 调平、连接、饰面、表面性能 | 始于基层板外表面 |

**协同场景**（墙面系统安装于隔墙系统之上时）：

```
隔墙系统（以轻钢龙骨隔墙为例）：
├── 天龙骨
├── 竖龙骨 + 隔声板
├── 空腔填充（岩棉）
├── 基层板（石膏板/硅酸钙板）← 隔墙系统终止界面
└── ↓
墙面系统（以调平龙骨饰面板为例）：
├── 调平龙骨（通过螺栓固定于隔墙基层板）
├── 空腔（墙面管线空间）
└── 饰面板 ← 墙面系统终止界面
```

**各标准中的边界规定**：

- **T/CECS 1018-2022 第3.0.3条**〔S1·条文号 2026-08-05 核验〕：当墙体为装配式隔墙时，应与装配式室内墙面系统集成
- **北京市导则 第2.0.4条**〔S1〕：集成隔墙系统 = 支撑骨架 + 填充材料 + 基板 + 饰面板 一体化设计
- **北京市导则 第2.0.5条**〔S1〕：调平龙骨饰面板墙面系统 = 独立于隔墙的墙面系统

**边界数据参考**（隔墙板材尺寸，主责技能为 prefab-partition-wall-solution，WS 仅在基层交接时引用）〔S1·北京市导则 表4.2.1-1〕：

| 类型 | 宽度（mm） | 长度（mm） | 厚度（mm） |
|------|-----------|-----------|-----------|
| 蒸压加气混凝土板 | 600 | 1800-6000 | 100, 120, 150, 200 |
| 轻质隔墙条板 | 600 | 2300-3000 | 90(100), 120, 200 |
| 骨架隔墙 | ≥600 | 1500-3660 | 90(100) |
| 集成隔墙模块 | 600, 900 | 2500-2800 | 90(100), 200 |

> 注：厚度不含饰面层厚度。
