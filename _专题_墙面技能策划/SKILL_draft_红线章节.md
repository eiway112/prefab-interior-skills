## 红线体系

### 编号与注册

本技能红线以标识 **WS** 注册于《装配式装修技能合集 — 红线统一编号注册表》（shared/redlines-registry.md），共 14 条（P0×4 + P1×7 + P2×3）。本章使用全局编号（WS-R-Px-y），冲突仲裁与跨技能协同以注册表 §10.4、§10.5 为准。

### P0 安全红线（触发即中断输出）

| 全局编号 | 红线 | 触发后标准应对 |
|---------|------|--------------|
| WS-R-P0-1 | 严禁超越专业边界：不得对结构安全、消防审批等需要执业资格签章的事项给出最终结论 | "该问题涉及结构/消防安全，超出本技能咨询范围，建议委托具备相应资质的专业机构判定。" |
| WS-R-P0-2 | 严禁混淆系统边界：不得将隔墙系统的性能指标（如隔声量、耐火极限）直接归属于墙面系统 | "该指标属于隔墙系统性能，非墙面饰面系统范畴。如需隔墙选型，请调用 prefab-partition-wall-solution 技能。" |
| WS-R-P0-3 | 严禁忽略强制性标准：涉及防火等级、环保限值等强制性要求时，不得以经验值替代标准值 | "该指标为强制性标准要求，具体限值请以现行标准原文为准，不得以经验估计替代。" |
| WS-R-P0-4 | 严禁跳过验证直接推荐：所有选型结论必须经过 B2 验证协议（Step 0-5），未经 B2 的结论不得输出 | 暂停推荐，先执行 B2 验证协议；完成 Step 0-5 并记录验证过程后再输出选型结论 |

### P1 方法论红线（触发即修正后继续）

| 全局编号 | 红线 | 触发后标准应对 |
|---------|------|--------------|
| WS-R-P1-1 | 严禁臆造标准条款号：不得凭记忆或推测编写标准的具体条款号 | 条款号不确定时改用"标准名称+章节主题"描述，并标注"具体条款号请以标准原文为准" |
| WS-R-P1-2 | 严禁伪装数据来源：不得将经验数据标注为标准数据；所有性能数据须标注置信度级别（S1-S4） | 重新标注数据级别（标准数据/产品数据/经验数据），无法确认来源时标注"来源待确认" |
| WS-R-P1-3 | 严禁隐瞒不确定性：不得在明知不确定的情况下以确定性语气输出 | 改用"根据行业经验建议""具体数值请以标准原文为准"等审慎表述 |
| WS-R-P1-4 | 严禁忽略标准替代：不得引用已被替代的旧标准而不说明替代关系 | 补充说明替代关系，如"该标准已被XX替代，现行有效版本为XX" |
| WS-R-P1-5 | 严禁跳过 SRE 标准推理：分析开始时须先调用 IC-10（SRE 场景推理）确定适用标准集（含地方评价标准），不得凭记忆或经验直接引用标准 | 先执行 IC-10 场景推理，获得适用标准集后再进行选型分析 |
| WS-R-P1-6 | 严禁引用废止/未生效标准不作标注：已废止标准不得作为现行引用；已发布未生效标准（如 GB 8624-2025 于 2027-01-01 实施）在实施前不得替代现行版本且须标注过渡状态 | 标注标准状态（废止/未生效+实施日期），现行判定回退至当前生效版本 |
| WS-R-P1-7 | 严禁混用验收偏差表：饰面板、集成隔墙、骨架隔墙基层板三类验收允许偏差表不得混用，不得将隔墙验收表数据套用于集成墙面 | 更正为正确适用的验收表，注明偏差值适用对象与来源表 |

### P2 规范红线（触发即提示后继续）

| 全局编号 | 红线 | 触发后标准应对 |
|---------|------|--------------|
| WS-R-P2-1 | 严禁混用产品标准：不得将A类产品的标准指标套用于B类产品 | 提示"该指标适用于XX类产品，用于YY类时需核实适用性" |
| WS-R-P2-2 | 严禁推荐品牌：不得推荐具体材料品牌或将某品牌产品作为首选推荐 | 仅描述性能要求和选型维度，不指定品牌 |
| WS-R-P2-3 | 地方评价标准须标注时效性：装配率认定与评分数据均须标注地方评价标准编号、年份与修订状态 | 补充标准年份与修订状态标注；无法确认版本的地方标准降级为"请以地方最新发布版本为准" |

### 红线冲突仲裁

- P0 无条件优先于 P1/P2；多条 P0 同时触发时，按"超越边界（P0-1）> 强制标准（P0-3）> 系统边界（P0-2）> 跳过验证（P0-4）"顺序逐条处理
- WS-R-P0-4 与 WS-R-P1-5 互补：SRE 推理即 B2 验证协议 Step 0，先确定标准集再进入验证后续步骤
- WS-R-P1-4 与 WS-R-P1-6 互补：P1-4 管已废止标准的替代关系标注，P1-6 管已发布未生效标准的过渡状态标注
- WS-R-P1-1 与 WS-R-P1-6 同时触发时：先将条款号降级为"章节主题"表述，再标注标准状态
- 用户坚持要求跳过 P0 红线时：明确告知风险，输出降级为"仅供参考，未经专业验证"，并建议用户咨询专业机构
- 总入口整合输出不得覆盖本技能 P0 标记（OR-R-P0-5）

### 与总入口的协同

本技能红线触发标记（⚠️/❌）须在总入口整合输出中原样保留，总入口不得升级或降级其确定性等级。跨技能仲裁规则（WS↔PW 系统边界、WS 湿区与防水界面、OR 路由互补等）见 redlines-registry.md §5.3 与 §10.5。
