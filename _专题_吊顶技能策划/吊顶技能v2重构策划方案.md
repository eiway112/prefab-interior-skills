## 一、选题依据

CL 是当前合集中 v2 范式缺口最突出的专项技能，依据四条：

1. **版本号与内容失真**：运行时标 2.0.0 但内容为 v1 范式，是合集唯一的"名实不符"技能。PW/FL/WS 均已完成实质 v2，CL 停在旧范式，红线未注册、无验证协议。
2. **红线注册缺位**：CL 本地已有 CL-R-P0-1~P2-2 共 9 条红线文本，但 redlines-registry §二映射表 CL 为"🔲 待注册"（L59），§11.1 预留注册时机为"吊顶技能 v2 重构"，预留红线规模 P0 2-3 条 + P1 4-5 条 + P2 3-4 条。本轮完成注册闭环。
3. **接口悬空**：IC-09（吊顶→ACE 空气声隔声）契约已在 interface-contracts v1.5.5 完成形式化（字段约束表 + JSON Schema），但 CL 运行时**零接线**；IC-10/SRE 亦零接线，SRE M3 激活表无吊顶域行。契约侧就绪、消费侧缺失，接线即闭环。
4. **内容厚度最低**：reference.md 仅 64 行、examples.md 仅 9 行，是三轮 v2 中内容创作量**最高**的一次（与 WS"复用 v1.2.0 已验证基线、创作量最低"相反）。须如实评估工作量，重点补 A 层声学/防火/机电原理与 B 层方法论。

### 2.2 CL 现有知识体（v1 已建，v2 保留重组）

三维分类矩阵（龙骨体系 × 面板类型 × 集成程度）、四条技术路线（集成模块化 / 轻钢龙骨板材 / 金属板 / 矿棉板）、机电管线协同表、检修策略表、六场景选型指引、七项施工控制点。以上内容为 v2 重组的素材基线，数据已带 S1/S3 分级标注（见 SKILL.md L48 数据分级说明），v2 保留并迁入 reference.md A/B 层。

### 2.3 CL 域特有判定逻辑（区别于 PW/FL/WS）

1. **声学定位是"贡献量"而非"判据"**：吊顶（隔声吊顶）对楼板/分户墙空气声隔声起**改善贡献**作用，本身不构成独立隔声判据——最终达标判断归宿主构件（楼板 L'nT,w、分户墙 DnT,w+C）。故 CL 接 IC-09 获取 Rw+C 估算区间，输出须强制标注"贡献量/估算，非构件判据"，并以宿主构件标准（GB 55038-2025 / GB 50118-2010）为达标归属。这是 CL 最易被误读的方法论点，须红线兜底。
2. **机电协同是核心决策域**：吊顶空腔是机电管线主要敷设空间，风管截面、喷淋/烟感点位、灯具独立吊挂决定吊顶最低标高与空腔高度。B 层须建机电协同与检修口方法论（PW/FL/WS 均无此域）。与 MI（prefab-mep-integration-system）的路由边界须明确。
3. **结构安全只转介不计算**：吊杆承载力、龙骨跨度、抗震构造属结构专业（CL-R-P0-1 已设边界），CL 仅做荷载提示与风险标注。
4. **吊顶耐火极限数据待 S1 核验**：SKILL.md L41 引用"GB 50016-2014 表 5.1.2 一级耐火等级吊顶 ≥0.25h（难燃性）"——吊顶作为建筑构件在表 5.1.2 中确有独立行（区别于 CG-20260807-017 裁定的"防火隔墙无独立行"），但本数据尚未经官方文本逐字核验，列入阶段 7 用 scanned-standard-clause-verify 核验。

### 3.3 B2 验证执行清单（六步骤，CL 特化版）

```
□ Step 0: 标准推理 — 调用 IC-10（SRE）确定适用标准集（吊顶域激活行，见 3.5）
□ Step 1: 输入解析 — 建筑类型、空间类型、结构楼板/吊挂条件、机电系统清单、
          空腔高度约束、防火等级、隔声/洁净/防潮特殊需求
□ Step 2: 三原则审查 — 场景匹配、标准时效性（GB 8624 过渡期）、声学贡献量边界
□ Step 3: 计算与核验 — 隔声需求 → 调 IC-09（ACE）估算吊顶 Rw+C 贡献区间，
          强制标注"贡献量/估算 ±4-6 dB/未考虑侧向传声"；
          防火/环保/验收 → 数据核验型（无独立计算）
□ Step 4: N 维度核验 — D1 防火/D2 结构荷载（转介）/D3 机电协同/D4 检修口/D5 标高
          /D6 隔声贡献/D7 环保/D8 施工平整度
□ Step 5: 输出组装 — 按 §9 输出模板结构化输出 + 贡献量声明 + 免责声明
```

### 3.4 红线体系升级（本地 9 条 → 预估 12 条）

保留本地全部 9 条（CL-R-P0-1~3、P1-1~4、P2-1~2），新增预估 3 条：

- CL-R-P1-5：严禁跳过 SRE 标准推理（对标 FL-R-P1-1 / WS-R-P1-5，Step 0 前置）
- CL-R-P2-3：吊顶声学输出须标注"贡献量/估算"——不得表述为构件隔声判据或检测值（对标 FL-R-P0-2 精神，结合 IC-09 调用约束）
- CL-R-P2-4：产品数据须标注来源与时效（对标 PW-R-P2-5 / FL-R-P2-4，>12 个月附过时警告）

合计 **P0×3 + P1×5 + P2×4 = 12 条**，落在注册表预留范围（P0 2-3 / P1 4-5 / P2 3-4）内。全部按 redlines-registry 统一编号规范注册 **CL 标识**（当前缺位），同步更新 §二映射表、§11.1 预留行、§12.2 统计。

### 3.5 SRE 集成（IC-10，M3 吊顶域激活行 — 新增）

SRE standards-reasoning-rules.md §三 M3 激活表当前无吊顶域行（PW/WS/FL 均有），本轮补入：
