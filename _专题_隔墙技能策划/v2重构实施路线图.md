# 装配式隔墙技能 v2 重构 — 分阶段实施路线图

> **文件定位**：基于《隔墙技能重构策划方案 v2》的实施规划，将重构工作分解为可独立验证的阶段性任务。
>
> **当前基线**：v1 已部署版本（SKILL.md 171 行 / 14.8KB，reference.md 427 行 / 31.8KB，examples.md 209 行 / 13.9KB）
>
> **目标架构**：5 文件体系（SKILL.md + reference.md + examples.md + product-solutions.md + atlas-index.md）+ 1 独立技能（acoustic-calculation-engine）
>
> **创建日期**：2026-06-11

---

## 总体设计原则

1. **逐阶段可部署**：每个阶段完成后，技能仍可作为独立可用的版本运行，不会出现"半成品"状态。
2. **逐阶段可验证**：每个阶段设置明确的验收门槛，通过 skill-qa-tester 验证后才进入下一阶段。
3. **高风险优先**：对技能行为影响最大的模块（验证协议、红线体系）尽早实施，留出充分的测试和调优时间。
4. **共享基础设施先行**：三份共享资源（glossary.md / interface-contracts.md / standards-index.md）已完成初稿，可在第一阶段即开始引用。
5. **增量替换而非全量重写**：旧 reference.md 的内容按模块逐步迁移到新结构，而非一次性删除重建。

### 8.1 目标

### 8.1A ACE 适用边界先行定义

> ACE 在建立公式库前，必须先声明适用范围、不可处理范围和输出确定性等级。凡超出适用边界的输入，不得继续给出确定数值，只能返回"超出模型适用范围/需人工评估"。

| 构造类型 | 可支持能力 | 输出等级 | 不得覆盖的范围 |
|---------|-----------|---------|---------------|
| 单层板/单一均质墙体 | 基于面密度的质量定律估算、吻合效应风险提示 | 专业估算 | 不替代实验室 Rw 检测报告 |
| 双层板龙骨墙 | MSM 共振频率、空腔深度、填充材料、连接方式影响判断 | 专业估算 | 不处理复杂节点侧向传声 |
| 双排龙骨/解耦构造 | 双空腔、解耦连接、岩棉填充对中高频隔声的风险判断 | 专业估算，需列关键假设 | 不保证现场 DnT,w+C 达标 |
| ALC/轻质条板 | 按条板厚度、面密度、接缝密封给区间估算 | 粗略估算 | 不处理板缝施工缺陷导致的离散偏差 |
| 异质复合墙 | 可做趋势判断和敏感性分析 | 仅供方案比较 | 不输出单一精确 dB 值 |
| 极端隔声需求（Rw+Ctr ≥60 dB） | 识别双空腔、声桥、密封、低频短板风险 | 风险审查优先 | 不承诺达标，必须建议专项声学设计/检测 |
| 信息不足输入 | 列出缺失字段并返回追问清单 | 参数不足 | 不做默认假设后直接计算 |

**统一不可处理范围**：现场侧向传声、门窗/检修口等薄弱构件、楼板/梁柱绕射、复杂节点泄漏、施工质量离散、房间混响时间修正、已安装现场实测替代判断。涉及这些因素时，ACE 必须提示需要现场检测或专项声学顾问复核。

## 回退策略

若某个阶段验证未通过，按以下规则处理：

| 情况 | 处理方式 |
|------|---------|
| 阶段 N 验证发现错误级问题 | 修复后重新执行该阶段验证，不进入阶段 N+1 |
| 阶段 N 验证发现警告级问题（≤3 条） | 记录问题，进入阶段 N+1，在后续阶段中修复 |
| 阶段 N 验证发现警告级问题（>3 条） | 暂停推进，集中修复后重新验证 |
| 阶段 7 集成验证未通过 | 根据失败原因定位到具体阶段，修复后从该阶段重新验证 |
| 阶段 8 ACE 与主技能联调失败 | 检查 IC-03 参数格式，分别排查 ACE 和主技能侧问题 |
