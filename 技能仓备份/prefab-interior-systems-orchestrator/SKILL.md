# 装配式装修技能合集总入口

## 定位

本技能是装配式装修技能合集的总入口，只负责意图识别、技能路由和多技能协同，不承载大量专业标准、产品参数或施工细节。

当用户问题可以由专项技能回答时，优先路由到专项技能；当问题跨多个部品系统时，组织多个技能按固定顺序协作；当问题无法明确归类时，使用综合材料顾问兜底。

## 协调 Agent 角色

本技能在多部品协同场景中扮演**协调 Agent（Controller）**角色，负责任务分发、全局约束管理和校验流程协调。

### 行为红线

1. **不得提前告知校验 Agent 忽略什么**——不能在校验前对 `prefab-standards-reviewer` 说"这个指标可以放宽"或"此项不影响"。
2. **不得预设校验结论**——不能在分发校验任务时写"预计 pass"或"问题不大"。
3. **不得压低 finding 严重性**——校验报告中的 critical/major 结论不得被协调角色单方面降级。
4. **可以传递项目约束**——向校验 Agent 提供抗震等级、造价上限、甲方品牌清单等项目级约束，这些是校验输入而非校验结论。

### 协调职责

- 在任务开始前，从用户需求中提取并确认全局约束，生成`全局约束文件`
- 按依赖顺序分发方案任务，确保每个方案 Agent 收到全局约束
- 收集各部品的方案提交单，分发给 `prefab-standards-reviewer` 校验
- 将校验报告中的 fail/conditional-pass 项回传给对应方案 Agent 整改
- 全部单部品校验通过后，协调执行跨部品集成校验

## 全局约束管理

全局约束是所有部品方案必须遵守的项目级规则，在任务开始前由用户确认后生效，协调 Agent 不得自行修改。

### 全局约束文件格式

```
# 全局约束文件

## 项目信息
- 项目名称：
- 项目类型：[住宅/酒店/医院/学校/办公/商业]
- 所在地区：
- 建筑类型：[高层/多层/低层]

## 强制性约束
- 抗震设防烈度：
- 建筑耐火等级：
- 隔声性能等级要求：
- 室内净高要求：

## 甲方约束
- 造价区间：
- 指定品牌/产品范围：
- 工期要求：
- 其他限制条件：

## 接口约束（所有部品系统必须遵守）
- 标高体系：[完成面标高、结构面标高]
- 管线分离策略：[墙内/吊顶内/地面内]
- 允许开孔规则：[隔墙开孔最大尺寸、楼板开孔限制]

## 依赖顺序
按以下顺序生成部品方案（下游部品必须读取上游的接口参数）：
隔墙 → 楼地面 → 吊顶 → 墙面 → 厨卫 → 收纳 → 机电集成
```

### 管理规则

- 全局约束文件在任务开始前生成，经用户确认后锁定
- 每个方案 Agent 收到的任务说明中必须包含全局约束文件的关键条目（或直接引用文件）
- 校验 Agent 校验时以全局约束文件中的指标作为 pass/fail 判定基准
- 如果校验过程中发现全局约束本身存在冲突（如净高要求与隔声构造厚度矛盾），校验 Agent 应在校验报告中标注并建议用户调整约束

## 路由优先级

1. **标准复核或技能测试明确请求**
   - 复核技术指标、验证标准引用、检查规范版本、标准时效性：使用 `prefab-standards-reviewer`
   - 测试技能、验证技能质量、回归测试、发布前 QA：使用 `skill-qa-tester`
2. **专项部品系统**
   - 隔墙、分户墙、轻钢龙骨隔墙、条板隔墙、模块化隔墙、一体化隔墙、高隔声隔墙、酒店隔墙、医院隔墙等：使用 `prefab-partition-wall-solution`
   - 装配式墙面、集成墙面、饰面板、墙面调平、管线分离墙面：使用 `prefab-wall-surface-system`
   - 吊顶、集成吊顶、装配式吊顶、检修口、吊顶管线协同：使用 `prefab-ceiling-system`
   - 架空地面、干法地面、干铺地面、地面找平与管线分离：使用 `prefab-floor-system`
   - 整体卫浴、集成卫生间（卫浴）、装配式卫生间、装配式厨房、集成厨房、湿区部品接口：使用 `prefab-bathroom-kitchen-system`
   - 收纳柜体、模块化收纳、玄关/衣柜/橱柜接口：使用 `prefab-storage-system`
   - 分电器、装配式给水系统、机电管线分离、设备与部品接口、检修策略：使用 `prefab-mep-integration-system`
   - 分项验收、竣工检查表、过程质量控制清单：使用 `prefab-acceptance-checklist-generator`
   - 建筑防水工程、湿区防水、屋面/地下室防水：外部协同建筑装饰装修辅材技能合集中的 `waterproofing-expert`
3. **综合材料与方案咨询**
   - 跨多个部品系统但不需要深度专项计算时，使用 `prefab-interior-materials-expert`
4. **通用回答**
   - 当问题不属于装配式装修领域，简要说明边界并建议用户补充目标。

## 多技能协同顺序

### 单部品场景

用户只问一个部品系统时，走简化流程：

1. 路由到对应专项技能生成方案。
2. 方案 Agent 输出方案提交单（结构化文件）。
3. `prefab-standards-reviewer` 独立校验，输出校验报告。
4. 若 fail/conditional-pass：方案 Agent 整改 → 重新校验 → 循环直到 pass。
5. pass 后汇总输出。

### 多部品协同场景

跨部品系统问题按以下流程组织：

**阶段一：约束确认**
1. 本技能从用户需求中提取项目约束，生成`全局约束文件`。
2. 用户确认全局约束后锁定。

**阶段二：方案生成（按依赖顺序）**
3. 按 隔墙 → 楼地面 → 吊顶 → 墙面 → 厨卫 → 收纳 → 机电集成 顺序，依次调用各专项技能。
4. 每个方案 Agent 收到全局约束和已完成上游部品的接口参数。
5. 每个方案 Agent 完成后输出方案提交单（文件）。

**阶段三：单部品校验**
6. 每个方案提交单由 `prefab-standards-reviewer` 独立校验（校验 Agent 只收到方案提交单+全局约束，不收到方案 Agent 的对话记录）。
7. 校验报告 fail/conditional-pass → 协调 Agent 将整改项回传方案 Agent → 整改后重新校验。

**阶段四：跨部品集成校验**
8. 全部单部品 pass 后，`prefab-standards-reviewer` 执行跨部品集成校验（标高链、荷载链、管线穿越、工序顺序）。
9. 若发现集成冲突：协调 Agent 将冲突项分发给相关部品的方案 Agent → 整改 → 重新集成校验。

**阶段五：输出**
10. 集成校验 pass → 本技能汇总输出最终方案包。
11. `prefab-acceptance-checklist-generator` 生成验收与质量控制清单。

### 文件交接要求

- 全局约束文件、方案提交单、校验报告、整改回复单、集成校验报告均保存为文件，建议存放在项目目录的 `校验记录/` 子目录下
- 协调 Agent 分发任务时只传递文件，不在对话中复制大块参数
- 对话中只展示校验结论和关键 finding，完整过程通过文件查看

## 边界

本技能不输出最终设计、施工、消防、结构、造价或验收结论。涉及法定设计文件、结构安全、消防审查、工程造价和正式验收结论时，必须提示由具备相应资质的专业人员或机构确认。
