## §1 M5 单值评价模型

浮筑地面撞击声改善量估算采用 M5 模型：

```
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C  [dB]
```

| 符号 | 含义 | 单位 | 说明 |
|------|------|------|------|
| m' | 浮筑面层单位面积质量 | kg/m² | 含砂浆、板材及附加荷载 |
| s | 弹性垫层动态刚度 | MN/m³ | 按厂家检测报告或标准试验取值 |
| C | 经验修正常数 | — | ACE 默认 C = 10 |

浮筑后撞击声压级估算：

```
Ln,w(浮筑) ≈ Ln,w(裸板) - ΔLw
```

> 精度声明：ΔLw 估算精度约 ±3-5 dB；Ln,w 估算精度约 ±4-6 dB，受垫层参数离散性、施工质量及边缝处理影响。详见 `reference.md §三 A2`。

## §2 共振频率与改善等级

| 共振频率 f₀ | 等级 | 说明 |
|------------|------|------|
| f₀ < 80 Hz | 优秀 | 全频段改善显著 |
| 80 Hz ≤ f₀ < 150 Hz | 良好 | 中高频段有效改善，低频段改善有限 |
| 150 Hz ≤ f₀ < 250 Hz | 一般 | 改善效果打折，低频段可能出现放大 |
| f₀ ≥ 250 Hz | 差 | 共振频率进入撞击声评价频段，改善效果有限 |

设计指引：住宅分户楼板浮筑构造宜控制 f₀ < 120 Hz，以确保 L'nT,w ≤ 65 dB 达标有足够余量。

## §四 楼板适用边界表

| 构造类型 | 是否适用 ACE IC-08 | 说明 |
|---------|-------------------|------|
| 浮筑砂浆面层 | 是 | M5 模型典型适用场景 |
| 浮筑板材面层 | 是 | 需将板材等效为面密度 m' |
| 架空地面 | 否 | 支撑脚-空腔系统不适用 M5，需采用 MSM/FE 模型 |
| 干法调平 | 否 | 隔声改善有限，通常不满足 L'nT,w ≤ 65 dB 高要求 |
| 快装地面 | 否 | 依赖垫层与锁扣构造，无通用模型 |
| 带地暖的浮筑地面 | 部分适用 | 地暖层计入 m'，但热工/结构边界需转介 |

不可处理因素（U-01 ~ U-08）：

| 编号 | 不可处理因素 | 处理方式 |
|------|--------------|---------|
| U-01 | 异形/非匀质基层楼板 | 转介专业声学模拟 |
| U-02 | 存在刚性声桥 | 先消除声桥再估算 |
| U-03 | 大面积开洞/管线穿越 | 转介专项设计 |
| U-04 | 缺乏弹性垫 s 参数 | 要求厂家提供检测报告 |
| U-05 | 基层楼板 Ln,w 未知 | 按经验基准取值并声明 |
| U-06 | 多层复合浮筑构造 | 简化等效或转介 FE 分析 |
| U-07 | 面层为特殊弹性材料 | 需校准 M5 常数 C |
| U-08 | 现场混响/侧向传声显著 | 现场检测替代估算 |
