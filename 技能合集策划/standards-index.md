## 一、使用说明

### 1.1 状态字段定义

本文件为每条标准维护以下状态字段，各子技能在引用标准时必须查阅本文件确认其当前状态。

| 状态字段 | 取值 | 说明 | 技能输出行为 |
|---------|------|------|------------|
| **标准状态** | `现行有效` | 标准正常实施中 | 正常引用 |
| | `即将实施` | 标准已发布但尚未到实施日期 | 引用时标注"该标准将于 YYYY-MM-DD 实施，当前设计仍以现行有效标准为准，本标准可作为前瞻性参考" |
| | `过渡期` | 新旧标准并行，过渡期内两者均可引用 | 同时列出新旧标准，标注"过渡期内新旧标准均可引用，建议优先采用新标准" |
| | `已废止` | 标准已失效，有替代标准 | 引用时标注"该标准已废止，现行替代标准为 [编号]"，并自动切换至替代标准条文 |
| | `已废止（无替代）` | 标准已失效，暂无直接替代 | 引用时标注"该标准已废止且暂无直接替代标准，建议咨询相关主管部门确认适用技术要求" |
| **被部分替代** | `被部分替代` | 标准的部分条文已被新标准替代，其余条文仍有效 | 引用被替代条文时标注"该条文已被 [新标准编号] 替代"；引用未替代条文时正常引用 |
| **官方核验日期** | `YYYY-MM-DD` | 最近一次在官方平台核实标准状态的日期 | 超过 6 个月未核验时标注"建议复核标准状态" |
| **来源链接** | URL | 核实标准状态的官方来源（如国家标准全文公开系统、住建部公告页） | 提供可追溯的核验依据 |
| **影响条文范围** | 条文编号/范围描述 | 该标准对技能合集的核心影响条文（非穷举，仅标注关键条文） | 引用时确认所引条文在影响范围内且仍有效 |
| **核验状态** | `已官方核验` / `待核验` / `到期需复核` / `无法核验` | 区分标准状态是否已由官方来源确认 | 只有`已官方核验`且未超过核验周期的标准，技能才可输出确定性状态；其余均须降级为"参考依据/待复核" |

### 1.1A 核验状态执行规则

| 核验状态 | 判定条件 | 技能输出行为 |
|---------|---------|-------------|
| 已官方核验 | 已通过国家标准全文公开系统、住建部官网公告或地方主管部门公开平台核实，且未超过核验周期 | 可按核验结论引用，并标注来源与核验日期 |
| 待核验 | 初稿录入或来自非官方二手资料，尚未取得官方来源 | 不得输出"现行有效"的确定性判断，只能写"本索引暂按[状态]记录，使用前需官方核验" |
| 到期需复核 | 曾核验，但强制性国标超过 3 个月、推荐性/产品/地方标准超过 6 个月未复核 | 可作为历史记录引用，但必须提示"状态到期需复核" |
| 无法核验 | 官方公开系统暂未检索到或来源不可访问 | 不作为合规结论依据，仅作为线索；重要项目需人工核验 |

**输出降级规则**：当标准的核验状态不是`已官方核验`时，所有技能不得把该标准作为唯一合规判据；涉及安全、消防、隔声强制指标时，应调用 IC-07 或提示用户通过官方渠道核实。

### 1.2 引用规则

1. **强制性国标**（GB 55xxx 系列、GB 50xxx 系列中的强制性条文）为不可逾越的红线，任何结论不得与之矛盾。
2. **推荐性标准**和行业标准作为技术支撑，引用时须标注标准层级。
3. **图集**作为构造做法参考，不作为唯一判据。
4. **产品标准**用于验证产品是否满足基本要求，不用于推荐产品。
5. **地方标准**引用时须确认项目所在地适用性，并在输出中注明。
6. 所有引用均须标注标准编号和年份，不得省略年份。

### 1.3 标准冲突处理规则

当不同层级或同层级的标准在同一指标上存在不同要求时：

| 冲突类型 | 处理规则 | 输出标注 |
|---------|---------|---------|
| 强制性国标 vs 地方标准 | 以强制性国标为最低要求；项目所在地地方标准指标**严于**国标时，优先执行地方标准 | "项目所在地 [地名] 执行的 [地标编号] 要求 [指标值]，严于国标 [指标值]，建议按地方标准执行" |
| 强制性国标 vs 推荐性标准 | 以强制性国标为准，推荐性标准仅作补充参考 | 标注推荐性标准的更高要求，明确"强制性要求以 [国标编号] 为准" |
| 不同地方标准之间 | 根据项目所在地确定适用标准，不适用的地方标准仅作对比参考 | "项目所在地适用 [标准 A]，不适用 [标准 B]（[B 所在地]标准）" |
| 同一标准的不同版本 | 以现行有效版本为准；过渡期内新旧版本均可引用时优先推荐新版 | 标注版本差异和过渡期状态 |
