## 三、两处功能常量为何不取占位或环境变量

`SCRATCH_ROOT` 是第七／九门禁建临时 git 仓与临时两镜像层的落点，该落点本身承担两条纪律：① 不落 C 盘；② 不进运行时技能目录（否则被 `sync_skill_backup.py` 当新增件带进镜像）。

- 改占位符 → 门禁直接跑不动；
- 改环境变量 → 纪律载体从**结构面**换成"靠有人记得设"，环境变量未设时默认落点会漂到 C 盘或仓内，属可失效约束，按「加固优先结构性隔离而非协议式约定」不采；
- 采**由件自身位置推导**：`REPO_ROOT`（＝`SCRIPT_DIR.parent`）与 `SCRIPT_DIR.parents[1]` 均已在件内定义／可直接取，推导结果与今日字面同路径。

等值自证（改后即跑，不依赖叙述）：

```
程序文件/cross_layer_eol_test.py      -> D:/Qoder-Files/_tmp-scripts/cross_layer_eol_scratch       逐字符等今日字面: True
程序文件/skill_cross_layer_test.py    -> D:/Qoder-Files/_tmp-scripts/skill_cross_layer_scratch     逐字符等今日字面: True
```

故本批不属"移动临时层落点"的门禁行为面变更，定级不因此升 A。
