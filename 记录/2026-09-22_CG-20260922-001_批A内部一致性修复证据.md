## 四、复算自证（数值由脚本现算）

### A 组｜缝隙损失表所绑的前提算不算得出来

复合式 `R = −10·lg[(1−p)·10^(−R_wall/10) + p·10^(−R_gap/10)]`，取 R_wall=30 dB、R_gap=0 dB：

- p = 0.0100% → 损失 0.41 dB
- p = 0.1000% → 损失 3.01 dB
- p = 1.0000% → 损失 10.41 dB
- 表列三档：0.01%→「约 0 dB」、0.1%→「约 2-4 dB」、1%→「约 8-12 dB」。复算值 0.41／3.01／10.41：后两档落在档内，最细档复算 0.41 而表记「约 0」→ 本批在 :302 显式披露该写法差异，不假装三档全等。
- 反向：R_wall=50 dB、p=0.1% → 损失 20.04 dB ⇒ 「R_wall 越高损失越大、本表不得套用」是算得出的（约 20 dB），非推测。

### B 组｜MSM 常数 600 与面密度无关

- `(1/2π)·√(ρ_air·c²·100)`，ρ_air=1.2 kg/m³、c=343 m/s → 598.01 ≈ 600。导出式内无 m₁／m₂ 项 ⇒ 原文「该常数仅在 m₁ ≈ m₂（对称构造）时精确有效」把**建模前提**误写成**常数适用前提**，本批订正为「常数的精确性不依赖 m₁ 与 m₂ 是否相近」。

### C 组｜架空地面两叶归属，错算差多少

- 正确两叶：M1=288（120mm 钢筋混凝土）、M2=30（纤维水泥板 25 ＋ PVC 5）→ 约化质量 m′ = 27.17 kg/m²；s_air = ρ_air·c²/d = 1.176e+06 N/m³（d=0.12 m）→ f₀ = 33.1 Hz。
- 原示例错法（把基层板、面层当两叶，结构楼板不入模）：M1=25、M2=5 → m′ = 4.17 kg/m² → f₀ = 84.6 Hz（即原文件所记 84.7 Hz）。
- 偏差 = √(m′_对／m′_错) = √(27.17／4.17) = 2.55 倍 ⇒ f₀ 被高估约 2.5 倍。原报「算高一个量级」与「质量比被夸大为 25∶5」两处均不成立（25∶5=5 小于 288∶30=9.6），本批已改为上述可复算表述，见 §六 第 2 项。

### D 组｜M7 端点排序（r<1 一侧）

- 变体 A：r = 145／172 = 0.8430 → 20·lg(r) = -1.48 dB、40·lg(r) = -2.97 dB ⇒ 升序端点 [-3.0, -1.5]、中值 -2.2 dB。r<1 时叠加界 40·lg(r) 更负＝区间下限，故原 `ΔR_low = 20·lg(r)／ΔR_high = 40·lg(r)` 的固定命名与同文件唯一算例（自行重排为 [−3.0, −1.5]）互斥，本批以 min/max 收口。

### E 组｜本批未修的三项不可复算／越域面（只登记，见 §七）

- FL-F02 总厚表列 83-85mm（`prefab-floor-system/reference.md:1005`）：按同文件 `:990—1001` 层次表逐项相加，含地暖管 Φ20 = 91-95 mm；不含管（视为嵌入保温／回填层）= 71-75 mm。**两口径区间均不含 83-85** ⇒ 表列值按其自身层次表不可复算。
