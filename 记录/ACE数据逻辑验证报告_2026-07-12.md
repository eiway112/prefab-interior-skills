## 二、物理公式数值交叉验证

### 2.1 验证用例

| 模型 | ACE 公式 | 对照来源 | 验证场景 |
|------|---------|---------|---------|
| M1 质量定律 | `Rw_base = 20·log10(m_total)` | reference.md `Rw ≈ 20lg(m) - 7` | T1 住宅分户墙，m_total=19.2 kg/㎡ |
| M2 吻合效应 | `fc = c²/(2π·h) × √(12(1-σ²)·ρ/E)` | reference.md 同形式 | 12mm 石膏板 |
| M3 MSM | `f₀ ≈ 600/√(d·m_red)` | reference.md `f₀ ≈ 1200/√(d·(m₁+m₂))` | T1 对称构造，d=7.5 cm，m₁=m₂=9.6 |
| M5 撞击声改善 | `ΔLw ≈ 18·log10(m') - 10·log10(s) + C` | 联调报告 V3 | V3 浮筑地面，m'=102，s=20，C=10 |

### 2.2 验证结果

**M1 质量定律**

```
ACE:    Rw_base = 20·log10(19.2) = 25.67 dB
REF:    Rw      = 20·log10(19.2) - 7 = 18.67 dB
差值:   7.00 dB
```

- 两公式形式仅差常数项 -7，ACE 采用更高基线。
- 即使按 ACE 基线，19.2 kg/㎡ 轻质构造的估算仍显著低于实验室典型值（45-50 dB），F1 已记录为方法论固有局限。
- **结论**：ACE M1 公式本身计算正确，但简化质量定律对轻质构造系统性低估，最终输出须依赖经验校准并明确标注。

**M2 吻合效应**

```
ρ=750 kg/m³, E=2.25 GPa, σ=0.23, h=0.012 m, c=343 m/s
fc = 343² / (2π × 0.012) × √(12 × (1-0.23²) × 750 / 2.25e9)
   ≈ 3038 Hz
```

- 与联调报告 V1 中的 3038 Hz 一致，与 QA 报告 T1 中的 3037 Hz 一致（四舍五入差异）。
- **结论**：公式实现正确。

**M3 质量-弹簧-质量模型**

```
ACE 简化:     f₀ = 600 / √(7.5 × 4.8) = 100.00 Hz
REF 简化:     f₀ = 1200 / √(7.5 × (9.6+9.6)) = 100.00 Hz
精确公式:     f₀ = (1/2π) × √(ρ₀c²/d × (1/m₁ + 1/m₂)) ≈ 100.08 Hz
```

- ACE `600/√(d·m_red)` 与 reference.md `1200/√(d·(m₁+m₂))` 在对称构造下完全等价。
- 与精确公式误差 <0.1%。
- **结论**：M3 简化公式可靠。

**M5 撞击声改善**

```
m'=102 kg/㎡, s=20 MN/m³, C=10
ΔLw = 18·log10(102) - 10·log10(20) + 10
    = 36.17 - 13.01 + 10
    = 33.16 dB
```

- 与联调报告 V3 重新计算后的 33.2 dB 一致。
- C 从 12 修正为 10 后，结果从 35.2 dB 降至 33.2 dB，更接近实测典型范围（25-30 dB）。
- **结论**：M5 公式与修正后的常数一致。

## 五、接口契约一致性

### 5.1 IC-03：隔墙技能 → ACE

**状态**：**待修复**

interface-contracts.md v1.4 中 IC-03 的 JSON Schema 仍为旧版扁平参数结构：

```json
{
  "板材类型": [...],
  "厚度": [...],
  "面密度": [...],
  "空腔深度": [...],
  "填充材料": [...],
  "龙骨类型": ...,
  "连接方式": ...,
  "密封方式": ...
}
```

而 ACE架构文档 §4.1 定义的 ACE-IN 为嵌套结构：

```json
{
  "调用方标识": { "技能标识": "PW", "计算类型": "空气声隔声", "评价量": "Rw+C" },
  "构造描述": {
    "构造类型": "双层板+空腔",
    "板材层": [...],
    "空腔层": [...],
    "支撑/连接系统": {...},
    "密封方式": "..."
  },
  "计算选项": {...}
}
```

**差异影响**：
- IC-03 Schema 缺少"调用方标识"和"计算选项"层，与 ACE-IN 不直接兼容。
- 字段命名不一致：IC-03 用"板材类型/厚度/面密度"平行数组，ACE-IN 用"板材层"对象数组。
- 缺少"构造类型"字段，ACE 无法自动判定构造分类。

**建议**：按 ACE-IN/ACE-OUT 通用 Schema 重写 IC-03 JSON Schema，或补充字段映射说明。

### 5.2 IC-08：楼地面技能 → ACE

**状态**：PASS

IC-08 已完整形式化为 ACE-IN/ACE-OUT 嵌套结构，字段、枚举、必填/可选关系与 ACE 架构文档一致。响应示例中的评价量、置信度、风险识别结构均符合 ACE-OUT。

### 5.3 IC-09：吊顶技能 → ACE

**状态**：**待补充**

interface-contracts.md line 412 明确标注"后续各接口（IC-02、IC-05、IC-06、IC-07、IC-09）应在对应子技能 v2 重构时按相同模式补充 Schema"。当前 IC-09 仅有请求/响应 JSON 示例，缺少：
- 字段约束表
- 请求 JSON Schema
- 响应 JSON Schema
- 降级行为字段级定义

**建议**：在吊顶技能接入 ACE 前补充 IC-09 形式化 Schema，避免与 IC-03/IC-08 验证强度不一致。

## 七、结论与建议

1. **物理内核可靠**：ACE M1-M6 公式实现正确，M3 简化公式与精确公式误差 <0.1%；M1 对轻质构造的系统性低估已通过校准和标注闭环。
2. **数据基线对齐**：材料参数、U 项范围、降级规则、精度声明在 QA 修复后跨文件一致。
3. **接口契约存在缺口**：IC-03 与 IC-09 的形式化程度落后于 IC-08，建议在下一阶段技能接入前补齐 Schema，确保隔墙、吊顶子技能与 ACE 的字段级兼容。

   - 修复 IC-03 JSON Schema，使其与 ACE-IN/ACE-OUT 对齐；
   - 补充 IC-09 字段约束表与 JSON Schema；
