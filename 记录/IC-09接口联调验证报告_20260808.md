### 计算过程（ACE 5 步估算法实算）

**Step 1 — 质量定律基线（K=0，CG-20260807-011 口径）**：

- 吊顶叶面密度 m_leaf = 9.0 × 2 = 18.0 kg/㎡（石膏板 750 kg/m³ × 0.012m × 2 层；700-800 区间对应 16.8-19.2）
- 宿主页面密度 m_host = 2400 × 0.12 = 288 kg/㎡（2300-2500 区间对应 276-300）
- 合计 m_total = 306 kg/㎡ → Rw_base = 20·lg(306) = **49.7 dB**
- 宿主单独隔声 Rw(host) = 20·lg(288) = **49.2 dB**（供贡献量换算）

**Step 2 — MSM 共振频率（M3，双叶构造禁用单叶 M1 做系统估算，CG-20260807-011）**：

- m_red = 18.0 × 288 / (18.0 + 288) = **16.94 kg/㎡**
- f₀ = 600 / √(20 × 16.94) = 600 / 18.41 = **32.6 Hz**
- 判定：f₀ < 100 Hz → 双层构造在整个计权范围内**有效增益区**
- 非对称比 m_host/m_leaf = 16.0 > 2 → 按 ACE 规则标注误差 5-13%；f₀ 计算精度约 ±10%（MSM 常数 600 隐含对称构造假设）

**Step 3 — 空腔增益叠加（M4）**：

| 增益项 | 取值 | 依据 |
|--------|------|------|
| 空腔深度增益（200mm > 150mm） | +6~10 dB | M4 深度增益表 |
| 填充增益（岩棉满填） | +3~5 dB | M4 填充增益表（容重 ≥60 kg/m³ 假设） |
| 解耦增益（弹性吊挂） | +3~5 dB | M4 解耦增益表（弹性连接档） |
| 合计 | **+12~20 dB** | — |

Rw_mid = 49.7 + (12~20) = **61.7~69.7 dB**（组合构造理想化值）

**Step 4 — 吻合效应检查（M2）**：

- 12mm 石膏板吻合频率 fc ≈ 3000 Hz（20260624 联调报告同规格公式复算约 3038 Hz）
- 双层同质板错缝安装 → 吻合谷分散；fc 位于计权频段中高段之外沿
- 风险等级：**低**（前提：双层错缝安装，已列假设）

**Step 5 — 声桥/缝隙修正（M6）**：

- 弹性吊钩（减振吊钩）+ 弹性连接 → 声桥风险**低**，无惩罚性扣减
- MS 密封胶收口 → 缝隙风险低，密封评估结论**充分**
- 模型为理想化构造模型，施工离散按 U-05（±3-8 dB）计入超出范围提示

## 六、Findings 与处置

### IT-1：IC-09 请求缺宿主构件描述字段（契约级，不阻塞）

**证据**：

1. IC-09 请求 Schema `additionalProperties: false`，构造描述仅含吊顶本体（板材层/空腔层/支撑/密封），宿主构件信息无字段可传
2. ACE reference 无 IC-09 宿主处理规则（grep "宿主/原顶"仅命中 IC-08 楼地面语境）
3. 契约响应示例（48-53 dB）未声明区间口径是"组合构造 Rw"还是"贡献量"，语义依赖调用方 A 层规则
4. M3 双叶模型需要双叶面密度，宿主缺失时模型左叶无输入——本次联调以"典型 RC 楼板"关键假设执行（第二节 ACE-IN 注记）

**影响**：贡献量口径目前由 CL A1.3 + CG-20260807-011 仲裁隐式承担；ACE 只能采用默认宿主假设并标注。功能可用但契约语义不完备。

**处置建议**（IC-09 v1.5.4，纳入后续契约修订批次）：

- 请求 Schema 增加可选对象字段 `宿主构件描述`（构件类型枚举 + 厚度_mm 或 面密度_kg_m2），缺失时 ACE 按典型构造假设并标注
- 或在契约调用约束中显式声明："ACE 输出为组合构造 Rw 区间；贡献量口径换算由发起方按各自 A 层规则执行，ACE 不承担贡献量换算"
- ACE reference 同步补充 IC-09 宿主缺省规则

**当前状态**：不阻塞联调与运行时运作；CL 调用前追问宿主条件（examples.md 示例 1 已示范），假设标注纪律已覆盖。

### IT-2：简化估算方法论悬空引用（CL 运行时 + 契约文本，B 级）

**证据**：A1.3、B5.4、interface-contracts.md IC-09 降级策略三处引用"reference.md 简化估算方法论"；grep 确认 CL reference 无该章节，唯一可执行兜底为 A1.2 v1 经验区间（5-15 dB〔S3〕）+ 贡献机制定性说明。

**处置**：阶段 7e 修正——A1.3/B5.4 引用改锚"A1.2 v1 经验区间 + 定性贡献机制说明"路径并明确降级标注措辞；interface-contracts.md IC-09 降级策略行同步修订（或注明落点）。属运行时 B 级变更，纳入 CG-023 范围，prefab-standards-reviewer 复核。

### IT-3：理想化模型区间与 v1 经验区间的封顶规则（CL 运行时 B5.3，B 级）

**证据**：

- Case 1 理想化贡献量 12.5-20.5 dB 高于 v1 经验区间 5-15 dB〔S3〕上限
- ACE 自身 U-01 声明："现场侧向传声未纳入模型，实际隔声量可能低于估算值 5-15 dB"——与 v1 经验区间的保守性互为佐证（理想化模型系统性偏乐观为模型固有属性，非本次联调异常）

**建议规则**（写入 B5.3 输出解读规则）：

> ACE 返回为理想化双叶模型区间（不含侧向传声、施工离散等现实折减）。CL 转述时执行**保守封顶**：输出下限 = min(ACE 下限, v1 经验下限)，输出上限 = min(ACE 上限, v1 经验上限)，并保留双来源标注（ACE 理想化模型区间 + v1 经验区间〔S3〕）。Case 1 换算：min(12.5, 5)=5，min(20.5, 15)=15 → 输出 **5-15 dB**。

该规则与 examples.md 示例 1 演示值（5-10 dB）兼容（演示值 ⊂ 封顶后区间）。阶段 7e 执行，纳入 CG-023，prefab-standards-reviewer 复核。
