# 装配式墙面系统详细参考

## 一、系统定义与分类体系

### 1.1 权威定义

**T/CECS 1018-2022 第2.0.1条**：装配式室内墙面系统（Interior assembled wall-finishing systems）——设置在室内基层墙体表面，由工厂生产，并主要采用干法装配而成的，满足功能和装饰要求的集成化墙面。

**T/CECS 1018-2022 术语体系**：

| 术语 | 定义 |
|------|------|
| 饰面板（2.0.2） | 由工厂生产、现场装配的装饰板材，分为单一材质饰面板和复合材质饰面板 |
| 部品（2.0.3） | 由工厂生产，构成装配式室内墙面系统的单一产品或复合产品组装而成的功能单元的统称 |
| 部件（2.0.4） | 在工厂或现场预先生产制作完成，构成装配式室内墙面系统构件的统称 |
| 挂法（2.0.5） | 采用金属挂件将饰面板悬挂在基层墙体上的一种挂装施工方法 |
| 粘结法（2.0.6） | 采用粘结材料将饰面板与基层紧密结合的一种施工方法 |
| 紧固件固定法（2.0.7） | 采用金属扣件、紧固件将饰面板固定在基层墙体上的一种施工方法 |
| 卡压法（2.0.8） | 采用卡压构件将饰面板卡压固定在基层上的一种施工方法 |

**北京市导则术语体系**：

| 术语 | 定义 |
|------|------|
| 饰面板（2.0.1） | 表面采用涂饰或包覆等工艺处理，具有装饰效果的板材 |
| 板材隔墙系统（2.0.2） | 采用专用固定卡件，将轻质墙板直接固定在建筑主体结构上，然后安装饰面板形成的隔墙系统 |
| 骨架隔墙系统（2.0.3） | 采用支撑骨架、填充材料和饰面板等在施工现场装配而成的隔墙系统 |
| 集成隔墙系统（2.0.4） | 在工厂将支撑骨架、填充材料和基板、饰面板等通过一体化设计、集成生产，在施工现场装配安装而成的隔墙系统 |
| 调平龙骨饰面板墙面系统（2.0.5） | 调平龙骨、连接件、饰面板通过设计集成，与基层墙体在施工现场装配而成的墙面系统 |

**广州市汇编术语**：

| 术语 | 定义 |
|------|------|
| 挂粘式 | 以专用卡件固定饰面板边部，饰面板中部采用结构胶点粘辅助粘接的组合连接方式 |
| 干挂式 | 以挂钩、挂码等挂装构造实现饰面板与龙骨或基层固定的连接方式 |
| 磁吸式 | 以磁性材料实现饰面板与龙骨固定的连接方式 |

### 1.3 系统层级关系

```
建筑主体结构（混凝土/砌体/钢结构）
├── 装配式隔墙系统（隔墙部品，止于基层板表面）
│   └── 基层板表面 = 墙面系统的安装基层
└── 装配式墙面系统（墙面部品，从基层板表面以上）
    ├── 调平层（如有）
    ├── 连接层（挂件/龙骨/胶粘剂）
    ├── 空腔层（管线分离空间，如有）
    └── 饰面板层（基层板 × 复合工艺）
```

## 三、工艺工法体系

### 3.1 GL工法（Gypsum Lining，石膏胶粘贴法）

**定义**：使用专用粘接石膏（GL胶）将石膏板直接粘贴于毛坯墙面（混凝土墙、砖墙、加气块墙），无需龙骨、无需墙面找平。

**构造特征**：
```
结构墙体（混凝土/砖/加气块）
└── 粘接石膏（找平+粘结一体化，20-25mm）
    └── 饰面板/石膏板基层
```

**技术参数**：
| 项目 | 数值 |
|------|------|
| 总厚度 | 20-25mm |
| 空腔 | 无（满粘） |
| 管线分离能力 | 无（需预埋或明装线槽） |
| 适用基层 | 混凝土墙、砖墙、加气混凝土砌块 |
| 基层平整度要求 | 无硬性要求（粘接石膏自带找平功能） |
| 施工速度 | 约为传统龙骨法的2倍 |

**优点**：施工速度快、学习门槛低（油漆工/木工简单培训即可上岗）、减少材料用量和空间占用
**局限**：敲击有空鼓声、隔声性能低于龙骨法、无法实现管线分离

### 3.2 UL工法（Ultra Light Gauge，超薄金属龙骨法）

**定义**：金属龙骨下地材通过专用弹性粘接剂固定于结构墙面，形成薄空腔的干式轻量化工法。日语称"乾式軽量フカシ壁工法"。

**构造特征**：
```
结构墙体
└── 弹性粘接剂（专用特殊弾性接着剤）
    └── 超薄金属龙骨（UL龙骨）
        └── 空腔（25-40mm，可走扁平线槽）
            └── 饰面板
```

**技术参数**：
| 项目 | 数值 |
|------|------|
| 总厚度 | 25-40mm |
| 空腔 | 25-40mm |
| 管线分离能力 | 较好，可走扁平线槽 |
| 适用基层 | 混凝土墙、加气混凝土砌块 |
| 抗震特性 | 弹性粘接提供抗震缓冲 |
| 连接方式 | 弹性粘接剂（非机械紧固） |

**优点**：抗震安全性高、形成有效空腔用于管线分离、可拆卸性优于GL法
**局限**：弹性粘接剂对基层清洁度要求高、成本高于GL法

### 3.3 LGS工法（Light Gauge Steel，标准轻钢龙骨法）

**定义**：采用标准轻钢龙骨系统通过调平螺栓/调平件固定于基层墙体，形成完整空腔的调平墙面系统。

**构造特征**：
```
结构墙体
└── 调平螺栓/调平件
    └── 轻钢龙骨（横龙骨+竖龙骨）
        └── 空腔（50-130mm+，标准线管敷设空间）
            └── 饰面板
```

**技术参数**：
| 项目 | 数值 |
|------|------|
| 总厚度 | 50-130mm+ |
| 空腔 | 50-130mm+ |
| 管线分离能力 | 最优，可走标准线管（含Φ20线管） |
| 适用基层 | 所有类型基层 |
| 基层平整度要求 | 无硬性要求（龙骨系统自带调平） |

**广州市汇编中的三级调平方案**：
| 方案 | 适用条件 | 空腔尺寸 |
|------|---------|---------|
| 卡件+胶粘 | 墙面平整度<5mm | 约10mm |
| 调平塞+龙骨 | 墙面平整度20-60mm | 30-70mm |
| U型支撑卡+龙骨 | 墙面平整度60-120mm | 30-130mm |

### 3.4 无龙骨点式调平

**复合铝蜂窝墙面**：
- 厚度：20-40mm
- 宽度：≤1200mm，标准600/900/1200mm
- 高度：≤3000mm
- 连接方式：专用角码固定，蝶芯榫卯连接相邻面板
- 基层要求：现有墙面平整度≤3mm
- 单点吊挂：50kg（重物需预埋加固板）

**石晶直挂墙面**：
- 厚度：4mm
- 宽度：≤1210mm
- 高度：≤2800mm
- 燃烧性能：B1级
- 基层要求：现有墙面平整度≤3mm
- 甲醛/苯/甲苯：未检出
- TVOC：≤25 μg/m³

### 3.5 干法直挂

**T/CECS 1018-2022 第5.4.3条 干挂法分类**：
| 干挂方式 | 特征 |
|---------|------|
| 开槽式通长挂件 | 面板边缘开槽，挂件插入槽内固定 |
| 压条式通长挂件 | 挂件压住面板边缘固定 |
| 自配合适式通长暗插件 | 面板与挂件自配合设计，暗装固定 |

### 3.6 磁吸式安装

**构造**：柔性磁条预先贴合于硅酸钙饰面板背面，通过磁力吸附于轻钢龙骨表面。

**特点**：
- 完全可逆安装，面板可随时拆卸更换
- 适用于需频繁检修机电管线的部位
- 单层隔声约45dB，双层约56dB（行业测试数据）
- 单层耐火约1.0h，双层约2.0h（行业测试数据）

## 四、管线分离详细设计

### 4.1 各技术路线管线分离方案

| 技术路线 | 管线敷设方式 | 空腔/线槽要求 | 适用管线类型 |
|---------|------------|-------------|------------|
| 板材隔墙 | 工厂预制线槽（槽深≤20mm） | 板内预埋 | 电线管、给水管（小口径） |
| 骨架隔墙 | 墙体空腔内走线 | 空腔≥50mm | 电线管、给排水管、暖通管道 |
| 集成隔墙 | 工厂预装管线和点位 | 模块内含 | 全类型（工厂集成） |
| 调平龙骨墙面 | 墙面与结构之间的空腔 | 空腔30-130mm | 电线管、扁平线槽 |
| 无龙骨点式 | 基层预埋或明装线槽 | 预埋深度≤20mm | 电线管（受限） |

### 4.2 管线分离设计要点（综合各标准）

1. **T/CECS 1018-2022 第3.0.2条**：系统应满足部品维修更换和管线维修的需要，应采用管线与结构分离技术
2. **北京市导则 第3.0.3条**：设备管线与结构分离原则，满足室内设备和管线的维修需要
3. **北京市导则 第6.2.4条**：
   - 板材隔墙管线在预制槽内
   - 骨架隔墙管线在墙体空腔内
   - 集成隔墙管线和点位在工厂预装
   - 调平龙骨墙面管线在墙面与结构之间的空腔内
   - 绝缘导线/电缆宜采用扁平线槽
4. **北京市导则 第5.2.4条**：接线盒须固定在横龙骨上；如与竖龙骨冲突，须增设附加横龙骨固定

## 六、与隔墙系统的技术边界

### 6.1 边界定义

**隔墙系统**的终止界面 = **墙面系统**的起始界面。具体而言：

| 系统 | 责任范围 | 终止/起始界面 |
|------|---------|-------------|
| 装配式隔墙系统 | 结构支撑、隔声、耐火、空腔管线 | 止于基层板（石膏板/硅酸钙板）外表面 |
| 装配式墙面系统 | 调平、连接、饰面、表面性能 | 始于基层板外表面 |

### 6.2 协同场景

当墙面系统安装于隔墙系统之上时：

```
隔墙系统（以轻钢龙骨隔墙为例）：
├── 天龙骨
├── 竖龙骨 + 隔声板
├── 空腔填充（岩棉）
├── 基层板（石膏板/硅酸钙板）← 隔墙系统终止界面
└── ↓
墙面系统（以调平龙骨饰面板为例）：
├── 调平龙骨（通过螺栓固定于隔墙基层板）
├── 空腔（墙面管线空间）
└── 饰面板 ← 墙面系统终止界面
```

### 6.3 各标准中的边界规定

- **T/CECS 1018-2022 第3.0.3条**：当墙体为装配式隔墙时，应与装配式墙面系统一体化设计
- **北京市导则 第2.0.4条**：集成隔墙系统 = 支撑骨架 + 填充材料 + 基板 + 饰面板 一体化设计
- **北京市导则 第2.0.5条**：调平龙骨饰面板墙面系统 = 独立于隔墙的墙面系统

## 九、装配率评价与"装配式"认定

### 9.1 各地评价标准对装配式墙面的认定规则

#### 通用认定三要素

各地方标准对"装配式墙面"的认定均需同时满足三个条件：
1. **集成化设计**（与管线、开关插座、吊顶、地面等一体化设计）
2. **工厂化生产**（部品部件在工厂预制完成）
3. **干式工法施工**（现场采用干作业施工工艺）

#### 饰面做法与"装配式"认定的关系（中国房地产业协会标准 条文说明 表2）

| 基层构造 | 饰面做法 | 是否认定为装配式墙面 |
|---------|---------|-------------------|
| 龙骨架空形式 | 一体化饰面板 | **符合** |
| 龙骨架空形式 | 免腻子+壁纸（壁布） | **符合** |
| 龙骨架空形式 | 基层板+一体化饰面板 | **符合** |
| 龙骨架空形式 | **涂料饰面** | **不符合** |
| 基点调平形式 | 一体化饰面板 | **符合** |
| 基点调平形式 | 免腻子+壁纸（壁布） | **符合** |
| 基点调平形式 | 基层板+一体化饰面板 | **符合** |
| 基点调平形式 | **涂料饰面** | **不符合** |

> **关键结论**：涂料饰面无论搭配何种基层构造，均不被认定为装配式墙面。壁纸（壁布）仅在"免腻子"前提下可认定。

#### 深圳市标准（SJG 159-2024）特殊规定

- **双条件缺一不可**："需同时满足工厂生产、现场干式工法施工两个条件才能认定为装配式装修"
- **明确排除**："墙面薄贴前进行湿作业抹灰的不计入装配式墙面面积"
- **合格材料清单**：金属集成板、竹（木）塑集成板、石塑集成板、陶瓷集成板、木质集成板、自饰面硅酸钙板、纤维增强水泥装饰板等
- **硬包排除示例**："以传统装修工程中的硬包安装为例，虽然满足干式工法要求，但若硬包为现场通过裁切、涂胶、包覆等流程制作而成，不满足工厂生产要求，则不被认定为装配式装修工艺"

#### 河南省导则（2024）逐房间认定标准

| 空间 | 合格的装配式墙面做法 |
|------|-------------------|
| 客厅/餐厅/卧室 | 集成板材墙面（金属集成板、竹木纤维板、石塑集成板、陶瓷集成板、木质集成板、无机类集成板）；成品模块墙面（金属制品、矿棉制品、石膏制品免腻子、玻璃制品、石材/瓷砖干挂、饰面有机物人造板、硫镁板） |

| 卫生间 | 彩钢板型/瓷砖型/岩板型聚氨酯发泡壁板、SPC饰面硫镁板复合壁板、SMC壁板 |

## 十、医疗建筑墙面专项要求

### 10.1 TCSUS 03-2019 医疗建筑集成化装配式内装修

**墙面系统设计要求**：
- 面板宜采用金属、玻璃纤维增强石膏(GRG)、硅酸钙板、玻璃等无机环保材料
- 有洁净要求的区域宜采用金属洁净板，相邻面板间密拼处理
- 龙骨与面板应采用挂钩式连接或卡扣式连接，且具备重复拆装功能
- 单一模块应可单独拆卸
- 阳角部品宜做成圆角，圆角半径不小于20mm
- 分室隔墙宜采用双空腔结构

**一体化医疗设备带**：
- 病房、产房等区域的医疗设备带宜集成设计嵌入墙体
- 设备带面板应与墙体齐平，并有可开启的装置
- 诊室等区域的观片灯、叫号机等宜集成设计嵌入墙体

### 10.2 TCSUS 48-2022 既有医疗建筑装配式改造

由金属、玻璃、无机板等面板，钢制龙骨，填充材料，门窗，一体化医疗设备带，一体化墙柜及相应五金配件组成。包含单空腔、双空腔墙体和墙面（板）。

**内墙部品定义**：

**医院案例参考**：
