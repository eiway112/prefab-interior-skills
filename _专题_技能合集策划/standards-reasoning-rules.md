## 一、标准分类协议（M1）

### 1.1 设计原则

中国建设领域标准编号遵循确定性编码规则。SRE 通过解析编号前缀即可判定标准的类型、层级、权限和地域范围，无需预知标准内容。这使得技能面对从未见过的标准编号时仍能正确分类。

### 1.2 编号模式语法

```
标准编号 := 前缀 [空格] 序号 [-分部] [-年份]
```

| 前缀模式 | 标准类型 | 默认层级 | 默认权限 | 地域范围 |
|---------|---------|---------|---------|---------|
| `GB 55xxx` | 全文强制性国标 | L1 | red_line | 全国 |
| `GB 50xxx` / `GB 5xxxx` | 含强制性条文的国标 | L1 | red_line | 全国 |
| `GB/T` | 推荐性国标 | L2 | binding_support | 全国 |
| `JG` / `JGJ` | 行业标准（建设） | L2 | binding_support | 全国 |
| `JG/T` / `JGJ/T` | 推荐性行业标准（建设） | L2 | binding_support | 全国 |
| `JC` / `JC/T` | 行业标准（建材） | L2 | binding_support | 全国 |
| `HG` / `HG/T` | 行业标准（化工） | L2 | binding_support | 全国 |
| `DB` + 省份代码 | 地方标准 | L2 | binding_support | 对应省份 |
| `DBJ` + 省份代码 | 地方建设标准 | L2 或 L4 | binding_support（设计/验收）或 reference（产品应用） | 对应省份 |
| `T/` + 机构代码 | 团体标准 | L2 | reference | 全国（适用性取决于管辖地是否采纳） |
| 数字+`CJ` / 数字+`J` / 数字+`ZJ` | 图集 | L3 | reference | 全国或区域 |
| `RISN-TG` | 技术导则 | L2 | reference | 全国 |

**省份代码对照表**（常用）：

| 代码 | 省/市 | 代码 | 省/市 | 代码 | 省/市 |
|------|------|------|------|------|------|
| 11 | 北京 | 31 | 上海 | 44 | 广东 |
| 33 | 浙江 | 35 | 福建 | 46 | 海南 |
| 32 | 江苏 | 61 | 陕西 | 41 | 河南 |

### 1.3 五步分类算法

对任何标准编号字符串 S，执行以下步骤：

**Step 1 — 解析前缀**：提取首个空格或数字序列之前的前缀，匹配 §1.2 语法表。输出：`standard_type`。

**Step 2 — 确定层级**：按 §1.2 表映射 L1-L4。

**Step 3 — 确定地域范围**：
- `DB`/`DBJ` 前缀：提取省份代码，查省份对照表
- 国标/行标：全国
- 团体标准：全国（但适用性由 §五 LA 规则判定）

**Step 4 — 确定性能领域**：从编号段和名称关键词推断：

| 编号段/关键词 | 性能领域 |
|-------------|---------|
| GB 55037, GB 50016, GB 50222, 07J905, "防火""耐火""燃烧" | fire |
| GB 50118, GB 55038, GB/T 50121, GB/T 19889, GB/T 45305, "隔声""声学" | acoustic |
| GB 55031, GB 50210, GB 55032, "验收""质量" | acceptance |
| JGJ/T 491, DB11/T 1553, DB33/T, "装配式""装配化" | prefab |
| GB 8624, GB/T 23451, JG/T 544, "产品" | product |
| "室内""空气""甲醛" GB 18580 | environmental |

**Step 5 — 组合分类结果**：

```
{
  标准编号: "GB 55038-2025",
  标准类型: "全文强制性国标",
  层级: "L1",
  权限: "red_line",
  地域范围: "全国",
  性能领域: ["acoustic", "acceptance"],
  分类置信度: "deterministic"
}
```

### 1.4 未知标准处理

| 情况 | 处理方式 |
|------|---------|
| 前缀可识别但编号不在 standards-index.md 中 | 确定性分类（confidence: deterministic），标注"未在索引中收录，建议通过官方渠道核实状态" |
| 前缀不可识别（新行业代码等） | 降级分类：authority=reference，confidence=inferred，标注"分类基于推断，请核实" |
| 编号格式异常（无法解析） | 拒绝分类，返回"编号格式异常，无法自动分类，请人工核实" |

### 1.5 特殊规则

| 规则 | 说明 |
|------|------|
| GB 55xxx 系列 | 无论主题，一律 L1 red_line。这是 2022 年后全文强制性标准的编号段 |
| GB 50xxx 系列 | L1 red_line，但须检查是否已被 GB 55xxx 部分替代 |
| "xxxx年版"标注 | 标准编号中的年份不变（如 GB 50016-2014），修订年份作为元数据（2018年版） |
| 同编号不同年份 | 分类相同，状态不同。须查 standards-index.md 确认时间状态 |

## 二、最小锚定集（M2）

### 2.1 锚定标准的角色

锚定标准不是"最重要的标准"，而是定义推理坐标系的基准点。它们校准每一层级的权限基准，为场景推理链提供确定性起点。

### 2.2 入选准则（满足至少一条）

| 准则 | 说明 |
|------|------|
| C1 层级定义性 | 该层级的典型范例，定义该层的权限基准和编号模式 |
| C2 跨技能引用 | 3 个以上子技能的核心引用标准 |
| C3 冲突裁决性 | 在其性能领域内裁决权限冲突（替代/优先关系） |
| C4 校准承载性 | 为 ACE 或其他计算引擎提供"计算值 vs 标准限值"的边界参考 |

### 2.3 锚定标准清单（13 条）

**L1 锚定（强制性国标，5 条）**

| A-L1-01 | GB 55031-2022 | C1+C2 | 民用建筑通用要求总纲，定义 L1 层级的权限基准 |
| A-L1-02 | GB 55037-2022 | C1+C3 | 防火通用规范，防火领域的最终裁决标准 |
| A-L1-03 | GB 55038-2025 | C3+C2 | 住宅项目规范，替代 GB 50118 住宅隔声条文，定义 DnT,w+C 强制指标 |

### 2.4 锚定集与 standards-index.md 的关系

- 锚定是 standards-index.md 条目的**属性标记**（`is_anchor: yes/no`），不创建独立数据文件
- standards-index.md 保留完整 46 条目录作为**版本注册中心**
- 锚定标记区分两种角色：**校准基准**（is_anchor=yes）和**版本追踪**（is_anchor=no）
- 技能文件只需引用 13 条锚定标准 + 推理引擎规则，无需复制完整目录

### 2.5 锚定集变更规则

| 变更场景 | 变更级别 | 说明 |
|---------|---------|------|
| 锚定标准被废止/替代 | **S 级（安全紧急）** | 锚定是推理链的承重结构，缺失会导致全链路失稳 |
| 新增 GB 55xxx 系列标准需评估为锚定 | **A 级** | 可能改变 L1 层级的权限基准 |
| 锚定标准的入选准则不再满足 | **B 级** | 降级为普通目录条目，选出新锚定 |
| 锚定集总数调整（13→N） | **A 级** | 影响全部技能的标准引用模式 |

## 三、场景→标准推理链（M3）

### 3.1 输入参数

```
项目类型：[住宅/酒店/医院/学校/办公/商业/其他]
空间类型：[分户墙/客房隔墙/走廊隔墙/卫生间/教室/病房/...]
项目所在地：[省/市，或"未提供"]
构造体系：[轻钢龙骨/条板/模块化/...]（可选）
性能需求：[隔声/耐火/防火/环保/验收/...]（可选，默认"按规范"）
```

### 3.2 六步推理算法

**Step 1 — 激活性能领域**

根据（项目类型, 空间类型）确定激活的性能领域集：

| 项目类型 | 空间类型 | 激活领域 |
|---------|---------|---------|
| 住宅 | 分户墙 | acoustic, fire, acceptance, prefab |
| 住宅 | 户内隔墙 | acoustic, fire, acceptance |
| 酒店 | 客房隔墙 | acoustic, fire, acceptance, prefab |
| 医院 | 病房/诊疗室 | acoustic, fire, acceptance, environmental |
| 学校 | 教室/实验室 | acoustic, fire, acceptance |
| 办公 | 办公室/会议室 | acoustic, fire, acceptance |
| 商业 | 商铺/展厅 | fire, acceptance |
| 医院 | 病房/手术部墙面 | fire, environmental, acceptance, prefab |
| 酒店 | 客房墙面 | acceptance, prefab, acoustic(边界提示) |
| 住宅 | 户内墙面 | prefab(认定), acceptance, environmental |
| 学校 | 教室墙面 | fire, environmental, acceptance |
| 办公 | 办公墙面 | acceptance, environmental, prefab |
| 厨卫湿区 | 墙板 | prefab, waterproof(外部协同), acceptance |
| 住宅 | 分户楼板 | acoustic(impact), fire, acceptance, prefab |
| 住宅 | 楼地面（一般） | acoustic(impact), acceptance, prefab |
| 酒店 | 客房地面 | acoustic(impact), acceptance, prefab |
| 办公 | 办公地面 | acceptance, prefab |
| 医院 | 病房地面 | acoustic(impact), acceptance, environmental |
| 学校 | 教室地面 | acoustic(impact), acceptance |
| 任意 | 任意 | fire, acceptance（始终激活的最小集） |

**Step 2 — 领域→标准族映射**

每个激活领域按建筑类型和构造体系查找对应标准族。

**acoustic 领域**：

| 建筑类型 | 标准族（按权限优先级排列） |
|---------|----------------------|
| 住宅 | GB 55038-2025（mandatory, DnT,w+C）→ GB 50118-2010（实验室参考）→ GB/T 50121-2005（评价量定义） |
| 非住宅 | GB 50118-2010（mandatory）→ GB/T 50121-2005（评价量定义） |
| +构造=轻钢龙骨 | → [+ GB/T 19889.x 系列（测量方法）, JG/T 544-2018（产品标准）, 07CJ03-1（L3 图集）, 08J931（L3 图集）] |
| +构造=条板 | → [+ GB/T 23451-2023（产品标准）] |

**acoustic(impact) 领域**（楼地面撞击声）：

| 建筑类型 | 标准族（按权限优先级排列） |
|---------|----------------------|
| 住宅分户楼板 | GB 55038-2025（mandatory, L'nT,w≤65dB）→ GB 50118-2010（非住宅参考）→ GB/T 50121-2005（评价量定义） |
| 非住宅 | GB 50118-2010（mandatory）→ GB/T 50121-2005（评价量定义） |
| +构造=浮筑地面 | → [+ GB/T 19889.7-2005（现场测量）, GB/T 19889.8-2006（ΔL实验室测量）, 08J931（L3 图集）] |
| +构造=架空地面 | → [+ 08J931（L3 图集）] |

**fire 领域**：

| 建筑类型 | 标准族 |
|---------|-------|
| 全部 | GB 55037-2022（mandatory）→ GB 50016-2014 2018版（补充，检查替代状态）→ GB 50222-2017（装修防火） |
| +涉及板材 | → [+ GB 8624-2012（燃烧性能分级）, 07CJ03-1（L3 图集，轻钢龙骨构造防火参考）] |

**acceptance 领域**：

| 建筑类型 | 标准族 |
|---------|-------|
| 全部 | GB 50210-2018（national）→ GB 55032-2022（质量控制）→ 07CJ03-1（L3 图集，轻钢龙骨验收参考） |
| +地点=浙江 | → [+ DB33/T 1168-2019] |
| +地点=北京 | → [+ DB11/T 1553-2025] |
| +地点=广东 | → [+ DBJ/T 15-208-2020] |
| +地点=上海 | → [待补充：上海地方验收标准（DB31 或 DG/TJ 08 系列），收录后须同步更新 standards-index.md] |

**prefab 领域**：

| 范围 | 标准族 |
|------|-------|
| 全国 | GB/T 51129-2017（评价）→ JGJ/T 491-2021（技术标准）→ RISN-TG 055-2025（导则） |
| +地点=浙江 | → [+ DB33/T 1259-2021] |
| +地点=北京 | → [+ DB11/T 1553-2025] |
| +地点=福建 | → [+ DBJ/T 13-428-2023] |
| +墙面饰面系统（WS 域） | → [+ T/CECS 1018-2022（待官方核验；墙面系统首要技术依据）, JG/T 579-2021（集成墙面产品）, JG/T 578-2021（墙板通用，与隔墙协同）] |

**environmental 领域**：

| 场景 | 标准族 |
|------|-------|
| 医院/学校 | GB 18580-2025（甲醛）→ GB 18582-2020（涂料有害物质）→ T/CSUS 03-2019（医院专项） |
| 住宅/酒店/办公（一般） | GB 18580-2025（甲醛；2026-06-01 实施，替代 GB 18580-2017） |

**Step 3 — 权限冲突裁决**

结果集中同一指标有多条标准覆盖时：

```
FOR 每对 (S_a, S_b) 覆盖同一指标:
  IF S_a.层级 < S_b.层级 (L1 < L2 < L3 < L4):
    S_a 优先作为合规判据，S_b 降级为"补充参考"
  IF S_a.层级 == S_b.层级 AND S_a 是地方 AND S_b 是全国:
    IF S_a 的指标值更严格:
      S_a 优先，标注"严于国标"
    ELSE:
      S_b 优先
  IF S_a 是团体标准 AND S_b 是推荐性国标:
    S_b 优先，除非合同文件指定 S_a
```

**Step 4 — 分配角色**

| 角色 | 定义 | 分配条件 |
|------|------|---------|
| mandatory_check | 必须校验合规，输出通过/不通过 | L1 标准中有适用的强制性条文 |
| design_basis | 设计值的主要依据 | L2 标准中有具体的设计阈值 |
| verification_reference | 用于校准/验证计算结果 | L2 方法/测量类标准 |
| construction_guide | 施工方法参考 | L3 图集、L4 产品标准 |
| prefab_evaluation | 装配率评价依据 | 装配式评价类标准 |

**Step 5 — 排序输出**

按角色优先级排列：mandatory_check → design_basis → verification_reference → construction_guide → prefab_evaluation

**Step 6 — 标注**

每条标准附：
- 分类记录（类型/层级/权限/地域/领域）
- 角色说明（在當前场景中的具体作用）
- 地域适用性标注（地方标准须注明是否适用）
- 替代/废止警告（如有）

### 3.3 输出格式

```
┌─ 强制性校验 (mandatory_check)
│  1. [标准编号]《标准名称》
│     层级: L1 | 权限: red_line | 领域: [domain] | 范围: [scope]
│     → [具体作用说明]
│
├─ 设计依据 (design_basis)
│  2. [标准编号]《标准名称》
│     层级: L2 | 权限: binding_support | 领域: [domain] | 范围: [scope]
│     → [具体作用说明]
│     [替代/废止警告（如有）]
│
├─ 验证参考 (verification_reference)
│  ...
│
├─ 施工指导 (construction_guide)
│  ...
│
└─ 装配式评价 (prefab_evaluation)
   ...
```

## 四、适用性裁判规则（M4）

### 4.1 地方标准适用性（LA 规则组）

| 规则编号 | 规则内容 |
|---------|---------|
| LA-1 | DB/DBJ 前缀地方标准**仅当**项目所在地匹配该标准的地域范围时适用 |
| LA-2 | 地方标准适用且其指标值**严于**对应国标时，地方标准优先。输出："项目所在地 [地名] 执行的 [地标编号] 要求 [指标值]，严于国标 [指标值]，按地方标准执行" |
| LA-3 | 不适用的地方标准（项目在异地）仅作"对比参考"。输出："[编号] 为 [地区] 地方标准，本项目所在地不适用，仅作参考对比" |
| LA-4 | 项目地点**未知**时，**必须追问**后才可引用任何地方标准。输出："请确认项目所在地，以便确定适用的地方标准"。此追问是强制行为，不可跳过 |

### 4.2 团体标准权限（GS 规则组）

| 规则编号 | 规则内容 |
|---------|---------|
| GS-1 | T/xxx 团体标准默认**不优先于** GB/T 推荐性国标（同一领域同一指标时） |
| GS-2 | 例外（团体标准优先）：(a) 项目合同文件明确指定执行 T/xxx；(b) 地方政府已将 T/xxx 纳入引用标准；(c) 该领域无 GB/T 存在（填补空白） |
| GS-3 | 团体标准指标更严但无 GS-2 例外时：以 GB/T 为设计依据，标注"团体标准 [编号] 要求更高（[指标值]），可自愿采用" |

### 4.3 时间适用性（TA 规则组）

| 规则编号 | 规则内容 |
|---------|---------|
| TA-1 | 状态为"即将实施"的标准：可作为前瞻性参考引用，**不得**作为合规判据。标注："该标准将于 YYYY-MM-DD 实施，当前仍以 [现行标准] 为准" |
| TA-2 | 状态为"被部分替代"的标准：引用的每条条文须逐一检查是否已被替代。被替代条文切换到替代标准；未替代条文正常引用并附注 |
| TA-3 | 状态为"已废止"的标准：**触发红线 PW-R-P1-7**。有替代标准时自动切换并告知用户；无替代标准时标注"已废止且暂无直接替代，建议咨询主管部门" |

### 4.4 跨领域标准（MD 规则组）

| 规则编号 | 规则内容 |
|---------|---------|
| MD-1 | 跨多个性能领域的标准（如 GB 55038-2025 同时涵盖隔声、结构、防火），在当前场景中对**所有相关领域**分别激活 |
| MD-2 | 每次激活独立计算角色。同一标准可能在隔声领域为 mandatory_check，在防火领域为 design_basis |
| MD-3 | 引用跨领域标准时，**必须指定条文/领域**：写"GB 55038-2025 §6.1.2（隔声性能）"，不得只写"GB 55038-2025" |

## 五、降级与兜底协议（M6）

| 降级场景 | 降级行为 | 输出标注 |
|---------|---------|---------|
| 标准编号无法分类（前缀不可识别） | 返回 unknown_type + reference 权限 + confidence=inferred | "标准 [编号] 的编号格式无法自动分类，请通过官方渠道核实" |

## 六、与现有架构的集成

### 6.1 与 IC-07（逐条核验）的两层协作

```
Layer 1 — IC-10（本引擎，场景查询）：
  分析开始时，确定本场景的适用标准集（面）
  → 技能据此构建分析框架

Layer 2 — IC-07（standards-reviewer，逐条核验）：
  输出生成时，验证每条引用的版本状态（点）
  → 技能据此调整具体引用

执行顺序：IC-10 先于 IC-07
```

### 6.2 与 ACE 计算引擎的三方分工

| 组件 | 职责 | 不做的事 |
|------|------|---------|
| ACE | 计算 Rw/DnT,w/f0 等物理值 | 不知道标准限值是什么 |
| SRE（本引擎） | 确定本场景的标准限值 | 不做任何物理计算 |
| 技能 B2 协议 | 将 ACE 输出与 SRE 阈值对比，做出合规判断 | 既不算物理值也不找标准 |

**SRE 驱动 ACE 评价量选择**：
- 住宅分户墙场景 → SRE 识别 DnT,w+C 为强制指标 → 技能请求 ACE 返回 DnT,w+C
- 办公隔墙场景 → SRE 识别 Rw+C 为设计指标 → 技能请求 ACE 返回 Rw+C

### 6.3 嵌入位置

SRE 嵌入 `prefab-standards-reviewer`（SR 技能），不作为独立技能。理由：
- SR 已有 IC-07 的标准核验基础设施
- IC-10 场景查询是 IC-07 逐条核验的自然扩展
- 避免增加独立技能带来的路由复杂性

### 6.4 与八步协同方法的集成

在 `interface-contracts.md` 定义的八步协同方法中，新增 **Step 0（标准推理）**：

```
Step 0: 标准推理（新增）
  总入口调用 IC-10，传递统一上下文
  获得本场景的适用标准集
  将标准集注入统一上下文，传递给所有子技能

Step 1-4: SRE 上下文增强
  Step 1 结合适用标准集明确各技能的标准约束范围
  Step 2 统一上下文增加【适用标准集】和【标准基准】
  Step 3 各技能须在适用标准集约束下分析，引用标准版本须与标准集一致
  Step 4 新增检查项：引用的标准是否均在适用标准集内

Step 5-7: 原有流程不变
```
