# 楼地面技能（FL）v2 重构策划方案

**策划日期**：2026-06-24
**技能标识**：FL（prefab-floor-system）
**基线版本**：v1（41 行 SKILL.md + 16 行 reference.md + 10 行 examples.md）
**目标版本**：v2（对标 PW v2 结构）

---

## 一、选题依据

FL 作为第二个全流程开发的领域技能，核心依据三条：

1. **技术验证维度**：FL 调用 ACE 的 IC-08 接口激活 M5 撞击声改善模型（ΔLw），PW 的 IC-03 仅触达空气声模型（M1-M3）。FL 将使 ACE 六大模型的验证覆盖达到 5/6。

2. **治理框架验证**：FL 涉及全新的标准域（撞击声标准族）、全新的评价量（Ln,w/ΔL）、全新的 SRE 场景映射——迫使治理框架暴露"非隔墙领域"盲点。

3. **基础设施就绪**：IC-08 已定义（v1.4），ACE M5 模型+楼板适用边界+弹性垫层参数已就绪，standards-index.md 已预留楼地面标准占位。

## 二、领域知识基线

### 2.1 核心标准体系

| 标准 | 层级 | 对 FL 的关键条文 | 状态 |
|------|------|----------------|------|
| GB 55038-2025 | L1 强制 | 住宅分户楼板 L'nT,w ≤ 65 dB（强制条文） | 现行有效（2025-05-01 实施） |
| GB 50118-2010 | L1 强制 | 非住宅撞击声限值（住宅条文已被 GB 55038-2025 废止） | 部分有效 |
| GB/T 50121-2005 | L2 推荐 | Ln,w / L'nT,w / ΔL 评价量定义 | 现行有效 |
| GB/T 19889.7-2022 | L2 推荐 | 撞击声隔声现场测量方法（代替 GB/T 19889.7-2005） | 现行有效（2023-02-01 实施） |
| 08J931 | L3 图集 | 隔声构造图集楼板节点 | 现行有效 |

### 2.2 GB 55038-2025 撞击声核心要求

**住宅分户楼板**：L'nT,w ≤ 65 dB（强制性条文，2025-05-01 起全面执行）

实际含义：裸楼板 + 瓷砖直贴（L'nT,w ~73-78 dB）不达标，必须设置弹性隔声层或浮筑构造。

**非住宅撞击声限值**（GB 50118-2010 仍有效部分）：

| 建筑类型 | 普通级 (dB) | 高要求级 (dB) |
|---------|-----------|------------|
| 学校教室 | ≤ 75 | ≤ 65 |
| 医院病房 | ≤ 75 | ≤ 65 |
| 酒店客房 | ≤ 75 | ≤ 55 |
| 办公室 | ≤ 75 | ≤ 65 |

### 2.3 四类技术路线

| 技术路线 | 构造特征 | 增加高度 | 撞击声改善 | 核心适用场景 |
|---------|---------|---------|-----------|-----------|
| 浮筑地面 | 弹性垫层+浮筑面层 | 50-80mm | ΔLw 18-25 dB | 住宅分户楼板（GB 55038-2025 达标） |
| 架空地面 | 支撑脚+基层板+面层 | 50-200mm | MSM 模型 | 管线分离、旧改、机房 |
| 干法调平 | 调平垫片+预制板材 | 20-40mm | 有限 | 办公、商业（隔声非核心） |
| 快装地面 | 直铺/锁扣/模块化 | 5-15mm | 取决于垫层 | 工期紧、标准化空间 |

### 2.4 关键物理参数

**弹性垫层动刚度**：

| 材料 | 动刚度 s (MN/m³) | 典型厚度 |
|------|----------------|---------|
| 橡胶隔声垫 | 10-30 | 5-10mm |
| PE 发泡垫 | 10-25 | 3-10mm |
| 聚氨酯发泡 | 15-40 | 5-15mm |
| 岩棉板 | 10-20 | 30-60mm |
| 软木垫 | 15-50 | 5-15mm |
| 复合隔声垫 | 5-15 | 5-10mm |

**M5 单值估算公式**（来源：ACE reference.md）：

```
f₀ = (1/2π) × √(s / m')  [Hz]
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C  [dB]  （C=10，ACE默认值）
Ln,w(浮筑) ≈ Ln,w(裸板) - ΔLw
```

**裸板基准值**：

| 楼板 | 面密度 (kg/m²) | Ln,w (dB) |
|------|-------------|----------|
| 100mm 钢筋混凝土 | ~240 | 78-82 |
| 120mm 钢筋混凝土 | ~288 | 76-80 |
| 150mm 钢筋混凝土 | ~360 | 74-78 |

### 2.5 常见失效模式

| 类型 | 表现 | 影响 |
|------|------|------|
| 声桥 | 浮筑层触碰周边墙体/管道穿越无隔离套管 | 隔声效果大幅降低（5-15 dB） |
| 边缝处理不当 | 缺少周边隔声垫条/用刚性材料填缝 | 形成声桥，破坏浮筑隔离 |
| 侧向传声 | 撞击能通过结构墙/柱绕过浮筑层 | 无法通过浮筑层解决 |
| 管道穿透 | 排水管/电气管与浮筑层刚性连接 | 形成声桥 |

### 3.4 红线体系（预估 16 条）

**P0 安全红线（5 条）**：FL-R-P0-1（不混淆评价量）、FL-R-P0-2（不将估算表述为检测值）、FL-R-P0-3（不隐瞒不确定性）、FL-R-P0-4（不超出专业边界）、FL-R-P0-5（不跳过验证直接推荐）

**P1 方法论红线（7 条）**：FL-R-P1-1（不跳过 SRE）、FL-R-P1-2（不基于废止标准）、FL-R-P1-3（不混淆实验室值与现场值）、FL-R-P1-4（不将示例作产品目录）、FL-R-P1-5（不编造标准条文号）、FL-R-P1-6（不忽略声桥风险）、FL-R-P1-7（不忽略标高约束）

**P2 规范红线（4 条）**：FL-R-P2-1（不伪造数据来源）、FL-R-P2-2（不推荐品牌）、FL-R-P2-3（不忽略标准更替）、FL-R-P2-4（产品数据标注时效性）

### 3.5 ACE 集成（IC-08）

调用时机：B2 验证协议 Step 3（计算验证）
评价量选择：SRE（IC-10）Step 0 确定——住宅分户楼板→Ln,w，面层改善→ΔL
输入参数：楼板基层+弹性垫层+面层/浮筑层，关键参数为垫层动刚度 s 和面层质量 m'
输出解读：ACE 返回 ΔLw 区间 → FL 计算 Ln,w_final = Ln,w_base - ΔLw → 合规判断由 A1 完成
降级策略：ACE 不可用时→reference.md 简化估算，标注"简化估算"

| 项目类型 | 空间类型 | 激活领域 |

| 住宅 | 楼地面（一般） | acoustic(impact), acceptance, prefab |
| 酒店 | 客房地面 | acoustic(impact), acceptance, prefab |
| 办公 | 办公地面 | acceptance, prefab |
| 医院 | 病房地面 | acoustic(impact), acceptance, environmental |
| 学校 | 教室地面 | acoustic(impact), acceptance |

新增 M3 Step 2 标准族映射：

| 领域 | 条件 | 标准族 |
|------|------|--------|
| acoustic(impact) | 住宅分户楼板 | GB 55038-2025(Ln,w) → GB 50118-2010(参考) → GB/T 50121-2005(评价量) → GB/T 19889.7(测量) |
| acoustic(impact) | 非住宅 | GB 50118-2010(强制) → GB/T 50121-2005(评价量) |
| acoustic(impact) | +构造=浮筑 | → [+ 08J931(L3图集), GB/T 19889.8(垫层ΔL测量)] |
