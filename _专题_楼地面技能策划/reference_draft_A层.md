## 一、定义与分类框架

### 1.1 装配式楼地面定义与三要素

**定义**：设置在建筑楼板基层之上，由工厂预制的构造层和部品在现场装配而成，满足承载、平整、隔声、防火等功能要求的集成化楼地面系统。

**三要素**：

| 要素 | 说明 | 典型内容 |
|------|------|---------|
| 基层 | 建筑结构楼板（混凝土、钢结构楼板等） | 100-150mm 钢筋混凝土 |
| 功能层 | 满足隔声/隔振/管线分离/调平等功能需求的构造层 | 弹性垫层、架空支撑、调平垫片 |
| 面层 | 最终行走面，满足装饰和使用功能 | 瓷砖、木地板、PVC、地毯等 |

### 1.2 四分类体系

| 类别 | 构造特征 | 增加高度 | 核心优势 | 核心约束 |
|------|---------|---------|---------|---------|
| 浮筑地面 | 弹性垫层+浮筑面层（砂浆或板材） | 50-80mm | 撞击声改善显著（ΔLw 18-25 dB） | 边缝隔声垫必须连续，声桥控制严格 |
| 架空地面 | 支撑脚+基层板+面层 | 50-200mm | 管线分离、检修便利 | 承载力设计、空鼓/异响控制 |
| 干法调平 | 调平垫片+预制板材 | 20-40mm | 施工快、标高影响小 | 隔声改善有限，适用非隔声场景 |
| 快装地面 | 直铺/锁扣/模块化面板 | 5-15mm | 工期短、标准化 | 对基层平整度要求高 |

### 1.3 分类→验证方式映射

| 分类 | 隔声验证方式 | 承载验证方式 | 平整度验证方式 |
|------|------------|------------|--------------|
| 浮筑地面 | ACE M5 模型（ΔLw 估算） + 现场 L'nT,w 检测 | 面密度+砂浆抗压 | 2m 靠尺 ≤3mm |
| 架空地面 | ACE M3+M5 模型 + 现场检测 | 集中荷载试验 | 2m 靠尺 ≤2mm |
| 干法调平 | 不要求隔声验证（除非另有需求） | 面荷载计算 | 2m 靠尺 ≤2mm |
| 快装地面 | 垫层 ΔL 测试报告（如适用） | 面荷载计算 | 2m 靠尺 ≤2mm（基层） |

### 1.4 用户表述→分类映射

| 用户表述关键词 | 映射分类 | 典型场景 |
|-------------|---------|---------|
| "楼上走路声音太响""分户楼板隔声" | 浮筑地面 | 住宅分户楼板 GB 55038-2025 达标 |
| "管线太多""需要检修""机房" | 架空地面 | 设备机房、旧改项目 |
| "地面不平""快速施工" | 干法调平 | 办公、商业空间 |
| "工期紧""标准化户型" | 快装地面 | 保障房、公寓标准化施工 |
| "地暖""地热" | 浮筑/架空（地暖兼容型） | 北方住宅 |

### 2.5 引用规则与标准冲突处理

1. **层级优先**：L1 > L2 > L3 > L4，冲突时以高层级为准
2. **时效优先**：同层级标准以最新发布/实施版本为准
3. **专项优先**：通用标准与专项标准冲突时，以专项标准为准（如 GB 55038-2025 住宅楼板要求优先于 GB 50118-2010 通用要求）
4. **地域补充**：地方标准高于国标时，应按地方标准执行（如上海、北京可能有更严要求）

### A2：撞击声理论

#### 撞击声与空气声的物理区别

| 维度 | 空气声隔声 | 撞击声隔声 |
|------|----------|----------|
| 声源类型 | 空气中传播的声波 | 直接作用于楼板的机械冲击 |
| 传播路径 | 声源→空气→隔墙→空气→受声侧 | 冲击源→楼板结构→辐射至楼下 |
| 评价量 | Rw/C/DnT,w（越高越好） | Ln,w/L'nT,w（越低越好） |
| 改善方向 | 增加质量/空腔/解耦 | 增加弹性隔离层/浮筑构造 |
| 改善量方向 | Rw 增加=隔声变好 | Ln,w 降低=隔声变好 |

> **红线提醒（FL-R-P0-1）**：Ln,w 数值越低表示隔声越好，与 Rw 方向相反。绝对不可在同一结论中混用 Rw 和 Ln,w。

#### 质量定律在撞击声中的表现

撞击声压级与楼板面密度的关系：

```
Ln,w ≈ K_mass - 20·log₁₀(m)  [dB]
```

其中 m 为楼板面密度（kg/m²），K_mass 为经验常数。

**核心结论**：楼板面密度加倍，撞击声压级约降低 6 dB。但单纯增加楼板厚度在实际工程中受结构限制，因此通常采用弹性隔离层（浮筑构造）来改善。

**裸楼板 Ln,w 基准值**：

| 楼板类型 | 厚度 | 面密度 (kg/m²) | Ln,w 基准 (dB) |
|---------|------|--------------|---------------|
| 钢筋混凝土 | 100mm | ~240 | 78-82 |
| 钢筋混凝土 | 120mm | ~288 | 76-80 |
| 钢筋混凝土 | 150mm | ~360 | 74-78 |
| 钢筋混凝土 | 200mm | ~480 | 72-76 |

#### 弹性垫层隔离原理

弹性垫层在浮筑构造中的作用类似于弹簧隔振器：

```
结构楼板 → 弹性垫层（弹簧） → 浮筑面层（质量块）
```

关键参数——动态刚度 s（单位：MN/m³）：
- s 越小，垫层越"软"，隔声效果越好
- s 受长期荷载压缩影响，实际使用中可能退化

**典型弹性垫层动态刚度**：

| 材料 | 动刚度 s (MN/m³) | 典型厚度 | 耐久性 |
|------|----------------|---------|--------|
| 复合隔声垫（橡胶+发泡） | 5-15 | 5-10mm | 较好 |
| 聚氨酯发泡垫 | 5-20 | 5-15mm | 中等 |
| 橡胶隔声垫 | 10-30 | 5-10mm | 好 |
| PE 发泡垫 | 10-25 | 3-10mm | 中等（长期压缩变形较大） |
| 软木垫 | 15-50 | 5-15mm | 好 |
| 岩棉板（高密度） | 10-20 | 30-60mm | 好（需注意防潮） |

#### 浮筑共振频率 f₀

浮筑地面可简化为单自由度弹簧-质量系统：

```
f₀ = (1/2π) × √(s / m')  [Hz]
```

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 弹性垫动态刚度 | s | N/m³ | 产品数据通常以 MN/m³ 标注，计算时需换算（1 MN/m³ = 10⁶ N/m³） |
| 浮筑层面密度 | m' | kg/m² | 面层+垫层上覆构造的总质量（不含弹性垫自身质量） |

**f₀ 与隔声效果的关系**：

| f₀ 范围 | 隔声效果评估 | 说明 |
|---------|------------|------|
| f₀ < 80 Hz | 优秀 | 共振频率远低于撞击声主要频率范围（100-3150 Hz），全频段有效改善 |
| 80 Hz ≤ f₀ < 150 Hz | 良好 | 中高频段有效改善，低频段改善有限 |
| 150 Hz ≤ f₀ < 250 Hz | 一般 | 改善效果打折，低频段可能出现放大 |
| f₀ ≥ 250 Hz | 差 | 共振频率进入撞击声评价频段，改善效果有限 |

**设计指引**：住宅分户楼板浮筑构造宜控制 f₀ < 120 Hz，以确保 L'nT,w ≤ 65 dB 达标有足够余量。

#### 撞击声改善量估算（ACE M5 模型）

单值评价公式（来源：ACE reference.md M5）：

```
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C  [dB]
```

C 为经验修正常数，ACE 默认 C=10。

**浮筑后撞击声压级估算**：

```
Ln,w(浮筑) ≈ Ln,w(裸板) - ΔLw
```

**精度声明**：ΔLw 估算精度约 ±3-5 dB，Ln,w 估算精度约 ±4-6 dB。受弹性垫参数离散性、施工质量和边缝处理影响。

#### 声桥效应对撞击声的影响

声桥是浮筑构造隔声失效的首要原因：

| 声桥类型 | 隔声损失 | 说明 |
|---------|---------|------|
| 边缝未设隔声垫条 | 5-15 dB | 浮筑层与周边墙体刚性接触 |
| 管道穿越无隔离套管 | 5-10 dB | 排水管/电管与浮筑层刚性连接 |
| 门槛处未做隔声断开 | 3-8 dB | 浮筑层在门洞口处连续 |
| 浮筑层内预埋刚性构件 | 3-8 dB | 钢筋/螺栓穿透弹性垫层 |
| 踢脚线刚性连接浮筑层和墙体 | 2-5 dB | 踢脚线同时固定于浮筑面和墙面 |

> **红线提醒（FL-R-P1-6）**：所有浮筑构造方案必须评估声桥风险，未评估声桥的方案不得输出。

### A3：结构荷载理论

#### 荷载分类

| 荷载类型 | 定义 | 楼地面相关 |
|---------|------|----------|
| 恒荷载（永久荷载） | 结构自重和固定附属物重量 | 浮筑层/架空层/面层自重 |
| 活荷载（可变荷载） | 人员、家具、设备等 | 按建筑功能分区取值 |
| 冲击荷载 | 短期动态作用 | 人员跳跃、重物坠落 |

#### 恒荷载计算

浮筑地面典型恒荷载：

| 构造层 | 厚度 | 面密度 (kg/m²) | 面荷载 (kN/m²) |
|--------|------|--------------|---------------|
| 弹性垫层 | 5-10mm | 2-8 | 0.02-0.08 |
| 浮筑砂浆层 | 40-50mm | 80-100 | 0.8-1.0 |
| 面层（瓷砖） | 8-12mm | 18-28 | 0.18-0.28 |
| **合计** | **55-72mm** | **100-136** | **1.0-1.36** |

架空地面典型恒荷载：

| 构造层 | 说明 | 面密度 (kg/m²) | 面荷载 (kN/m²) |
|--------|------|--------------|---------------|
| 支撑脚（均摊） | 按间距 600mm 计算 | 3-5 | 0.03-0.05 |
| 基层板（硅酸钙/纤维水泥） | 12-18mm | 15-28 | 0.15-0.28 |
| 面层 | 瓷砖/木地板/PVC | 8-28 | 0.08-0.28 |
| **合计** | | **26-61** | **0.26-0.61** |

> **注意**：浮筑地面比架空地面恒荷载大 2-3 倍，需确认结构楼板承载力足够。

#### 活荷载标准值（GB 50009-2012）

| 建筑功能 | 均布活荷载 (kN/m²) | 集中荷载 (kN) |
|---------|-------------------|-------------|
| 住宅 | 2.0 | 2.0 |
| 办公 | 2.5 | 2.0 |
| 商业 | 3.5 | 3.5 |
| 学校教室 | 2.5 | 3.0 |
| 医院病房 | 2.0 | 2.0 |

#### 架空体系承载力设计要点

1. **支撑脚间距**：一般 450-600mm，间距越小承载力越高但施工成本增加
2. **集中荷载验算**：架空层应满足 3.0-4.0 kN 集中荷载（模拟家具腿/设备支点）
3. **挠度控制**：基层板跨中挠度 ≤ L/300（L 为支撑脚间距）
4. **抗震要求**：高层建筑架空地面需考虑水平力作用下的稳定性

> **红线提醒（FL-R-P0-4）**：结构承载力详细计算应由结构工程师完成，FL 仅做初步判断和风险提示，不得输出结构安全结论。

### A4：标高控制与管线分离

#### 完成面标高推算

完成面标高（FFL, Finished Floor Level）由各构造层厚度叠加确定：

```
FFL = 结构楼板标高 + 各构造层厚度之和
```

**典型构造层厚度**：

| 构造类型 | 组成 | 总厚度范围 |
|---------|------|----------|
| 浮筑地面 | 弹性垫(5-10) + 砂浆(40-50) + 面层(8-12) | 53-72mm |
| 浮筑地面（干式） | 弹性垫(5-10) + 板材(12-20) + 面层(5-12) | 22-42mm |
| 架空地面 | 支撑脚(30-150) + 基层板(12-18) + 面层(5-12) | 47-180mm |
| 干法调平 | 调平垫(5-15) + 板材(12-20) | 17-35mm |
| 快装地面 | 直铺面层(5-12) | 5-12mm |

#### 标高协调要点

| 协调对象 | 协调要求 | 常见问题 |
|---------|---------|---------|
| 门洞 | 完成面标高确定后才能定门高 | 门底留缝过大/门扇刮地 |
| 楼梯 | 首步/末步踏步高度须与完成面匹配 | 踏步高差不一致 |
| 厨卫 | 厨卫完成面宜低于相邻房间 10-20mm | 高差方向错误导致倒泛水 |
| 电梯 | 电梯门槛与楼层完成面标高匹配 | 门槛高差过大 |
| 净高 | 层高 - 楼板厚 - 地面构造厚 - 吊顶 = 净高 | 净高不满足规范最低要求 |

> **红线提醒（FL-R-P1-7）**：所有楼地面方案必须包含完成面标高推算，未考虑标高约束的方案不得输出。

#### 管线分离构造处理

**架空地面管线分离**：

| 管线类型 | 管径范围 | 穿越架空层要求 |
|---------|---------|---------------|
| 给水管 | DN15-DN32 | 架空层内水平走管，支撑脚间穿越 |
| 排水管 | DN50-DN110 | 需预留坡度，可能需局部降低架空层 |
| 电气管线 | DN16-DN25 | 架空层内走管，穿基层板处设护套 |
| 暖通管道 | DN50-DN150 | 大管径需专项设计架空层高度 |

**浮筑地面管线处理**：

| 场景 | 处理方式 | 隔声风险 |
|------|---------|---------|
| 管线预埋在结构楼板内 | 无需穿越浮筑层 | 无额外风险 |
| 管线从浮筑层下穿越 | 设弹性套管隔离 | 中等——套管密封不良形成声桥 |
| 管线从浮筑层上引出 | 预留开孔+弹性密封 | 高——开孔处浮筑层不连续 |
| 地漏穿越浮筑层 | 独立套管+弹性密封+隔声环 | 高——必须专项设计 |

### A5：验收框架

#### 撞击声现场检测

**检测方法**：GB/T 19889.7-2022 规定的标准打击器法

**核心步骤**：
1. 在楼板上方放置标准打击器（5 个锤头，每个 0.5 kg，落差 40mm）
2. 在楼下房间测量撞击声压级（1/3 倍频程，100-3150 Hz）
3. 计算标准化撞击声压级 L'nT,w（含混响时间修正）

**L'nT,w 与 Ln,w 的区别**：

L'nT,w 是现场评价指标，将实测声压级归一化至参考混响时间 T₀=0.5s（对应约 10 m² 吸声量的标准接收室）。Ln,w 是实验室评价指标，归一化至 T₀=1.0s。二者的参考条件不同，数值不可直接比较。

实际现场测量中，接收室混响时间通常大于 0.5s（空房间可达 1.0-2.0s），经归一化修正后 L'nT,w 可能低于实测声压级。同时，现场侧向传声、施工质量等因素可能导致实测结果高于理想预期。两种效应方向相反，最终结果取决于具体条件。

> **注意**：FL 输出中引用撞击声检测结果时，必须标注使用的评价量是 L'nT,w 还是 Ln,w，不得混用。

#### 平整度验收

| 验收标准 | 检测方法 | 允许偏差 |
|---------|---------|---------|
| 表面平整度 | 2m 靠尺 + 塞尺 | ≤ 2mm（架空/干法）、≤ 3mm（浮筑砂浆面） |
| 相邻板块高差 | 钢直尺 + 塞尺 | ≤ 0.5mm（瓷砖）、≤ 1.0mm（木地板） |
| 踢脚线上口直线度 | 拉 5m 线 + 钢直尺 | ≤ 2mm |

#### 标高复核

| 检查项 | 方法 | 允许偏差 |
|--------|------|---------|
| 完成面标高 | 水准仪/激光水平仪 | ≤ ±5mm |
| 相邻房间高差 | 钢直尺 | 按设计要求（厨卫低 10-20mm） |
| 门槛高差 | 钢直尺 | ≤ 3mm |

#### 浮筑构造专项检查

| 检查项 | 要求 | 常见缺陷 |
|--------|------|---------|
| 边缝隔声垫 | 连续、无断开、宽度≥面层厚度 | 局部遗漏、被砂浆挤入 |
| 管道穿越处理 | 弹性套管+密封胶 | 刚性穿越、密封不完整 |
| 浮筑层连续性 | 无裂缝、无刚性连接点 | 温度裂缝、预埋件穿透垫层 |
| 控制缝 | 间距≤6m（砂浆面层） | 未设控制缝导致不规则开裂 |

#### 架空构造专项检查

| 检查项 | 要求 | 常见缺陷 |
|--------|------|---------|
| 支撑脚稳定性 | 无晃动、底座平整 | 底座未找平、支撑脚松动 |
| 基层板固定 | 板间留缝 2-3mm、螺钉间距≤300mm | 板缝过大/过小、固定不牢 |
| 空鼓检查 | 敲击无空鼓声 | 基层板与支撑脚接触不良 |
| 行走异响 | 正常行走无异响 | 支撑脚与基层板摩擦、板材翘曲 |
