## 三、交叉一致性验证

### 检查点 3.1：IC-10 请求参数格式一致性

**结果：FAIL（发现不一致）**

| 维度 | FL SKILL.md §11 | interface-contracts.md IC-10 | 差异说明 |
|------|----------------|------------------------------|---------|
| 参数 1 | `project_type` | `项目类型` | 命名语言不同（不影响功能） |
| 参数 2 | `space_type` | `空间类型` | 命名语言不同（不影响功能） |
| 参数 3 | `construction_type="floor"` | `构造体系`（如"轻钢龙骨/条板/模块化/..."） | **语义不匹配** |
| 参数 4 | `performance_domains` | `性能需求` | 命名不同（不影响功能） |
| 参数 5 | **缺失** | `项目所在地` | **FL 请求中未包含** |

**差异分析**：

1. `construction_type="floor"` 表示的是构造类别（地面 vs 墙面），而 IC-10 的 `构造体系` 期望的是具体构造类型（如"浮筑地面""架空地面"）。SRE Step 2 的映射表使用 `+构造=浮筑地面` 和 `+构造=架空地面` 来激活附加标准族（如 GB/T 19889 系列），因此 FL 应传递具体构造类型而非泛化的 "floor"。

2. `项目所在地` 缺失会导致 SRE 触发 LA-4 规则（地方标准追问），无法激活地方标准族（如 DB11/T 1553-2025、DB33/T 1168-2019 等），降低标准推理的完整性。

### 检查点 3.2：评价指标一致性（Ln,w 住宅 vs L'nT,w 非住宅）

**结果：PASS**

| 场景 | FL SKILL.md A1 摘要 | FL reference.md A1 完整版 | SRE M3 Step 2 映射 | 一致性 |

| 住宅分户楼板 | L'nT,w ≤ 65 dB | L'nT,w ≤ 65 dB | L'nT,w ≤ 65 dB（GB 55038-2025） | 三方一致 |
| 学校教室 | Ln,w ≤ 75/65 dB | Ln,w ≤ 75/65 dB | Ln,w（GB 50118-2010） | 三方一致 |
| 医院病房 | Ln,w ≤ 75/65 dB | Ln,w ≤ 75/65 dB | Ln,w（GB 50118-2010） | 三方一致 |
| 酒店客房 | Ln,w ≤ 75/55 dB | Ln,w ≤ 75/55 dB | Ln,w（GB 50118-2010） | 三方一致 |
| 办公室 | Ln,w ≤ 75/65 dB | Ln,w ≤ 75/65 dB | Ln,w（GB 50118-2010） | 三方一致 |

评价量区分（住宅 L'nT,w vs 非住宅 Ln,w）在三份文件中完全一致。酒店客房的高要求级限值（≤ 55 dB）严于其他非住宅场景（≤ 65 dB），体现了酒店对隔声的更高要求，与 GB 50118-2010 原文一致。

### 检查点 3.3：FL 降级兜底（A1 表）vs reference.md A1 实际内容

**结果：PASS**

## 五、修复建议

### 建议 #1：修正 FL SKILL.md §11 IC-10 请求参数（对应不一致项 #1、#2、#3）

将 FL SKILL.md §11 的 IC-10 调用规范中请求参数修改为与 interface-contracts.md IC-10 定义一致的格式：

**修改前**：
```
请求参数：{project_type, space_type, construction_type="floor", performance_domains}
```

**修改后**：
```
请求参数：{项目类型, 空间类型, 项目所在地, 构造体系="[浮筑地面/架空地面/干法调平/快装地面]", 性能需求}
```

**修改理由**：
1. `构造体系` 传递具体构造类型（如"浮筑地面"），使 SRE Step 2 能正确激活构造增强映射路径（如浮筑地面 → GB/T 19889.7 + GB/T 19889.8 + 08J931）
2. 补充 `项目所在地`，使 SRE 能激活地方标准族（如 DB11/T 1553-2025）
3. 统一使用中文参数命名，与 interface-contracts.md 保持一致
